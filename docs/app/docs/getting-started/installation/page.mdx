# Installation

Get started with Oxygenix UI in your React project.

## System Requirements

Before you begin, ensure you have the following installed:

-   **Node.js**: v18.0.0 or higher
-   **React**: v18.0.0 or higher
-   **TypeScript**: v5.0.0 or higher (recommended)

## Install Oxygenix UI

Install the UI package and the tokens package (for themes).

<LiveCodeBlock>
    <LiveSource
        code={`npm install @oxygenix-ui/ui @oxygenix-ui/tokens`}
        language="bash"
    />
</LiveCodeBlock>

## Peer Dependencies

Oxygenix UI relies on `react` and `react-dom`.

## Setup Styles

To load the design system, import the theme and component styles in your root layout file (e.g., `app/layout.tsx` or `src/main.tsx`).

<LiveCodeBlock>
    <LiveSource
        code={`// 1. Import the theme (CSS Variables)
import '@oxygenix-ui/tokens/themes/enterprise.css'

// 2. Import component styles
import '@oxygenix-ui/ui/styles.css'`}
        language="tsx"
    />
</LiveCodeBlock>

### Common Issues

### Styles not loading
Make sure you have imported **BOTH** the theme (`enterprise.css`) and the component styles (`styles.css`). The component styles rely on variables defined in the theme.

### TypeScript errors
If you see type errors, ensure your `tsconfig.json` is configured with `"moduleResolution": "bundler"`.
