# Support Oxygenix UI

Oxygenix UI is an open-source project, built and maintained by a dedicated community of developers. We believe in creating high-quality, accessible, and beautiful UI tools that are free for everyone to use.

## Why Support Matters

Building and maintaining an enterprise-grade UI library takes a significant amount of time and effort. From triaging issues and reviewing pull requests to writing documentation and developing new features, there is always work to be done.

Your support allows us to:
- Dedicate more time to maintenance and development.
- Cover hosting and infrastructure costs for our documentation and examples.
- continuously improve the quality and accessibility of our components.

We are incredibly grateful for every contribution, whether it's code, documentation, or financial support.

## Ways to Support

### GitHub Sponsors

If you or your company uses Oxygenix UI in your projects and would like to support our growth, please consider sponsoring us on GitHub. Your sponsorship is a direct way to say "thank you" and help sustain the project for the long term.

[Become a Sponsor](https://github.com/sponsors/oxygenix-ui)

### Contribute Code and Documentation

Financial support is not the only way to help! We value every bug report, feature request, and pull request. If you're interested in contributing code or improving our documentation, please check out our Contributing Guide.

[Read the Contributing Guide](/docs/contributing)

### Share the Love

Simply using Oxygenix UI and sharing it with your network helps us grow.
- Star us on [GitHub](https://github.com/oxygenix-ui/oxygenix-ui).
- Follow us on Twitter/X.
- Blog about your experience using Oxygenix UI.

## Company Sponsorship

For companies relying on Oxygenix UI for critical applications, sponsorship ensures that the tools you use remain healthy and actively maintained. It also offers a way to get visibility in front of our community of developers.

If you're interested in discussing a corporate sponsorship tier with dedicated benefits, please reach out to us.
