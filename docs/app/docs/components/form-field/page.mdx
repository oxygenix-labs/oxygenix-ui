# FormField

A wrapper component that provides context, labels, and error messages for form inputs.

## Overview

The FormField component standardizes the presentation of form controls. It handles the rendering of labels, required indicators, helper text, and error messages in a consistent accessible layout.

## Import

<LiveCodeBlock>
    <LiveSource
        code={`import { FormField } from '@oxygenix-ui/ui';`}

</LiveCodeBlock>

## Basic Usage

Wrap any form control (like `Input`, `Select`, `Textarea`) with `FormField`.

<LiveCodeBlock>
    <LivePreview>
        <FormField label="Username" htmlFor="username-basic">
            <Input id="username-basic" placeholder="Enter username" />
        </FormField>
    </LivePreview>
    <LiveSource
        code={`import { FormField, Input } from '@oxygenix-ui/ui';

export default function BasicDemo() {
  return (
    <FormField label="Username" htmlFor="username-basic">
      <Input id="username-basic" placeholder="Enter username" />
    </FormField>
  );
}`}
        language="tsx"
    />
</LiveCodeBlock>

### Validation Errors

Pass an error message string to the `error` prop to display it. This typically puts the wrapped input into an error state as well, but you should also pass `error` to the input itself for visual consistency.

<LiveCodeBlock>
    <LivePreview>
        <FormField 
            label="Email" 
            htmlFor="email-error" 
            error="Please enter a valid email address."
            required
        >
            <Input type="email" id="email-error" error defaultValue="invalid-email" />
        </FormField>
    </LivePreview>
    <LiveSource
        code={`import { FormField, Input } from '@oxygenix-ui/ui';

export default function ErrorDemo() {
  return (
    <FormField 
        label="Email" 
        htmlFor="email-error" 
        error="Please enter a valid email address."
        required
    >
        <Input type="email" id="email-error" error defaultValue="invalid-email" />
    </FormField>
  );
}`}
        language="tsx"
    />
</LiveCodeBlock>

## Accessibility

- **Label Association**: The `htmlFor` prop on `FormField` MUST match the `id` prop on the child input. This ensures that when a user clicks the label, focus is transferred to the input, and screen readers correctly identify the input.
- **Required Indicator**: The `required` prop adds a visual indicator (usually an asterisk) and ensures screen readers know the field is mandatory.

## Props

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `label` | `string` | - | The text label for the field |
| `htmlFor` | `string` | - | The ID of the input being labeled |
| `hint` | `string` | - | Helper text displayed below the input |
| `error` | `string` | - | Error message displayed below the input |
| `required` | `boolean` | `false` | Whether the field is required |
| `children` | `ReactNode` | - | The form control to wrap |
| `className` | `string` | - | Additional CSS class |

## Common Mistakes

### Forgetting htmlFor/id

The most common mistake is omitting the `htmlFor` prop on FormField or the `id` prop on the input. Always ensure they are present and identical.

### Using for non-form elements

Do not use `FormField` to wrap non-interactive content just for styling. It renders a `<label>` element which expects an interactive control.
