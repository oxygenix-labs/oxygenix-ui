# RadioGroup

A component for selecting a single value from a set of options.

## Overview

The RadioGroup component allows users to select one option from a list. It manages the state and layout of a group of radio buttons.

## Accessibility

- **Grouping**: The component automatically groups inputs using the `name` prop.
- **Role**: Renders a `radiogroup` role wrapper.
- **Keyboard**: Arrow keys are used to navigate between radio options.

## Props

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `name` | `string` | **Required** | The name attribute for input grouping |
| `options` | `{ label: string, value: string, disabled?: boolean }[]` | **Required** | Array of options |
| `value` | `string` | - | Selected value (controlled) |
| `onChange` | `(value: string) => void` | - | Change handler |
| `horizontal` | `boolean` | `false` | Display horizontally |
| `className` | `string` | - | Additional CSS class |

## Common Mistakes

### Missing Name Prop

The `name` prop is crucial for radio buttons to work as a group. Without it, verifying one radio button won't uncheck the others in the native HTML behavior.

### Controlled State complexity

When using controlled state (`value` and `onChange`), ensure `onChange` passes the selected string value back to your state setter.
