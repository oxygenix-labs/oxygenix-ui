# RadioGroup

Radio button group component for mutually exclusive selections with proper grouping and accessibility.

## Installation

```bash
npm install @oxygenix-ui/forms
```

## Basic Usage

```tsx
import { Form, Field } from '@oxygenix-ui/forms';

function SurveyForm() {
  return (
    <Form onSubmit={(data) => console.log(data)}>
      <Field
        name="satisfaction"
        label="How satisfied are you?"
        type="radio"
        required
        options={[
          { value: 'very-satisfied', label: 'Very Satisfied' },
          { value: 'satisfied', label: 'Satisfied' },
          { value: 'neutral', label: 'Neutral' },
          { value: 'dissatisfied', label: 'Dissatisfied' },
        ]}
      />
      <button type="submit">Submit</button>
    </Form>
  );
}
```

## Features

### Controlled Grouping

Radio buttons are automatically grouped by the `name` prop.

```tsx
<Field
  name="plan"
  label="Select a plan"
  type="radio"
  required
  options={[
    { value: 'free', label: 'Free - $0/month' },
    { value: 'pro', label: 'Pro - $10/month' },
    { value: 'enterprise', label: 'Enterprise - Custom pricing' },
  ]}
/>
```

### Disabled Options

Disable specific radio options.

```tsx
<Field
  name="plan"
  label="Select a plan"
  type="radio"
  options={[
    { value: 'free', label: 'Free' },
    { value: 'pro', label: 'Pro' },
    { value: 'enterprise', label: 'Enterprise (Coming Soon)', disabled: true },
  ]}
/>
```

### With Descriptions

Add descriptions to options using custom render.

```tsx
function PlanSelector() {
  const plans = [
    {
      value: 'free',
      label: 'Free',
      description: 'Perfect for personal projects'
    },
    {
      value: 'pro',
      label: 'Pro',
      description: 'For professional developers'
    },
    {
      value: 'enterprise',
      label: 'Enterprise',
      description: 'For large teams and organizations'
    },
  ];

  return (
    <Field
      name="plan"
      label="Choose your plan"
      render={({ field }) => (
        <div>
          {plans.map(plan => (
            <label key={plan.value} style={{ display: 'block', marginBottom: '12px' }}>
              <input
                type="radio"
                name={field.name}
                value={plan.value}
                checked={field.value === plan.value}
                onChange={() => field.onChange(plan.value)}
              />
              <div>
                <strong>{plan.label}</strong>
                <p style={{ margin: 0, color: '#666' }}>{plan.description}</p>
              </div>
            </label>
          ))}
        </div>
      )}
    />
  );
}
```

## API Reference

### Field (Radio)

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `name` | `string` | Required | Field name (groups radio buttons) |
| `label` | `ReactNode` | - | Group label |
| `type` | `'radio'` | Required | Must be 'radio' |
| `options` | `Option[]` | Required | Radio options |
| `required` | `boolean` | `false` | Whether selection is required |
| `validate` | `ValidationFunction \| ValidationFunction[]` | - | Validation function(s) |
| `disabled` | `boolean` | `false` | Whether all options are disabled |
| `description` | `string` | - | Help text below the radio group |

### Option

| Property | Type | Description |
|----------|------|-------------|
| `value` | `string \| number` | Option value |
| `label` | `string` | Option label |
| `disabled` | `boolean` | Whether option is disabled |

## Keyboard Navigation

The RadioGroup supports full keyboard navigation:

- **Tab**: Move between radio groups
- **Arrow Up/Down**: Select previous/next option
- **Arrow Left/Right**: Select previous/next option
- **Space**: Select focused option

## Accessibility

The RadioGroup component is fully accessible:

- **Fieldset/Legend**: Proper grouping with semantic HTML
- **ARIA**: Full ARIA attribute support
- **Keyboard**: Complete arrow key navigation
- **Screen Reader**: Group and options announced correctly
- **Focus**: Clear focus indicator

## Best Practices

### 1. Use for Mutually Exclusive Choices

```tsx
// ✅ Good - one choice only
<Field
  name="gender"
  label="Gender"
  type="radio"
  options={[
    { value: 'male', label: 'Male' },
    { value: 'female', label: 'Female' },
    { value: 'other', label: 'Other' },
  ]}
/>

// ❌ Bad - use checkboxes for multiple selections
<Field name="interests" type="radio" options={interests} />
```

### 2. Provide Clear Labels

```tsx
// ✅ Good - descriptive labels
<Field
  name="plan"
  label="Subscription Plan"
  type="radio"
  options={[
    { value: 'free', label: 'Free - For personal use' },
    { value: 'pro', label: 'Pro - For professionals' },
  ]}
/>

// ❌ Bad - vague labels
<Field
  name="plan"
  type="radio"
  options={[
    { value: 'free', label: 'Option 1' },
    { value: 'pro', label: 'Option 2' },
  ]}
/>
```

### 3. Limit Number of Options

```tsx
// ✅ Good - reasonable number of options
<Field name="size" type="radio" options={['S', 'M', 'L', 'XL']} />

// ❌ Bad - too many options (use Select instead)
<Field name="country" type="radio" options={allCountries} />
```

### 4. Use Select for Many Options

If you have more than 5-7 options, consider using a Select instead:

```tsx
// ✅ Good - Select for many options
<Field name="country" type="select" options={countries} />

// ❌ Bad - Radio for many options
<Field name="country" type="radio" options={countries} />
```
