# TableToolbar

Flexible toolbar component for data tables with search/filter inputs, bulk actions (shown when rows selected), export buttons, and dynamic left/right content slots.

## Installation

```bash
npm install @oxygenix-ui/data
```

## Basic Usage

```tsx
import { DataTable, TableToolbar } from '@oxygenix-ui/data';

function UsersPage() {
  const [search, setSearch] = useState('');

  return (
    <div>
      <TableToolbar
        left={
          <input
            type="search"
            placeholder="Search users..."
            value={search}
            onChange={(e) => setSearch(e.target.value)}
          />
        }
        right={
          <Button leftIcon={<Plus />}>Add User</Button>
        }
      />
      <DataTable data={filteredUsers} columns={columns} />
    </div>
  );
}
```

## Features

### Search Input

Add search functionality to filter table data.

```tsx
function SearchableTable() {
  const [search, setSearch] = useState('');

  const filteredData = data.filter(item =>
    item.name.toLowerCase().includes(search.toLowerCase())
  );

  return (
    <>
      <TableToolbar
        left={
          <div style={{ display: 'flex', gap: '8px' }}>
            <input
              type="search"
              placeholder="Search..."
              value={search}
              onChange={(e) => setSearch(e.target.value)}
            />
          </div>
        }
      />
      <DataTable data={filteredData} columns={columns} />
    </>
  );
}
```

### Bulk Actions

Show actions when rows are selected.

```tsx
function TableWithBulkActions() {
  const [selected, setSelected] = useState([]);

  return (
    <>
      <TableToolbar
        left={
          selected.length > 0 ? (
            <div style={{ display: 'flex', gap: '8px', alignItems: 'center' }}>
              <span>{selected.length} selected</span>
              <Button variant="danger" onClick={() => deleteSelected()}>
                Delete
              </Button>
              <Button variant="secondary" onClick={() => exportSelected()}>
                Export
              </Button>
            </div>
          ) : (
            <input
              type="search"
              placeholder="Search..."
            />
          )
        }
      />
      <DataTable
        data={data}
        columns={columns}
        selection={{
          mode: 'multi',
          selectedRows: selected,
          onSelectionChange: setSelected,
        }}
      />
    </>
  );
}
```

### Export Buttons

Add export functionality for data.

```tsx
<TableToolbar
  left={<input type="search" placeholder="Search..." />}
  right={
    <div style={{ display: 'flex', gap: '8px' }}>

        Export CSV

      <Button variant="ghost" onClick={() => exportPDF()}>
        Export PDF
      </Button>
      <Button leftIcon={<Plus />}>Add Item</Button>
    </div>
  }
/>
```

### Filter Dropdowns

Add filter controls to refine data.

```tsx
function FilterableTable() {
  const [status, setStatus] = useState('all');
  const [role, setRole] = useState('all');

  return (
    <>
      <TableToolbar
        left={
          <div style={{ display: 'flex', gap: '8px' }}>
            <input type="search" placeholder="Search..." />
            <select value={status} onChange={(e) => setStatus(e.target.value)}>
              <option value="all">All Status</option>
              <option value="active">Active</option>
              <option value="inactive">Inactive</option>
            </select>
            <select value={role} onChange={(e) => setRole(e.target.value)}>
              <option value="all">All Roles</option>
              <option value="admin">Admin</option>
              <option value="user">User</option>
            </select>
          </div>
        }
        right={
          <Button onClick={() => clearFilters()}>Clear Filters</Button>
        }
      />
      <DataTable data={filteredData} columns={columns} />
    </>
  );
}
```

## API Reference

### TableToolbar

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `left` | `ReactNode` | - | Left content slot (search, filters) |
| `right` | `ReactNode` | - | Right content slot (actions, buttons) |
| `className` | `string` | - | Additional CSS class |

### With Advanced Filters

```tsx
function AdvancedFilterTable() {
  const [filters, setFilters] = useState({
    search: '',
    status: 'all',
    dateRange: 'all',
    sortBy: 'name',
  });

  return (
    <>
      <TableToolbar
        left={
          <div style={{ display: 'flex', gap: '8px', flexWrap: 'wrap' }}>
            <input
              type="search"
              placeholder="Search..."
              value={filters.search}
              onChange={(e) => setFilters({ ...filters, search: e.target.value })}
            />
            <select
              value={filters.status}
              onChange={(e) => setFilters({ ...filters, status: e.target.value })}
            >
              <option value="all">All Status</option>
              <option value="active">Active</option>
              <option value="pending">Pending</option>
              <option value="archived">Archived</option>
            </select>
            <select
              value={filters.dateRange}
              onChange={(e) => setFilters({ ...filters, dateRange: e.target.value })}
            >
              <option value="all">All Time</option>
              <option value="today">Today</option>
              <option value="week">This Week</option>
              <option value="month">This Month</option>
            </select>
          </div>
        }
        right={
          <div style={{ display: 'flex', gap: '8px' }}>
            <Button variant="ghost" onClick={() => resetFilters()}>
              Reset
            </Button>
            <Button leftIcon={<Download />} onClick={() => exportData()}>
              Export
            </Button>
          </div>
        }
      />
      <DataTable data={filteredData} columns={columns} />
    </>
  );
}
```

### With Refresh Button

```tsx
function RefreshableTable() {
  const [loading, setLoading] = useState(false);

  const handleRefresh = async () => {
    setLoading(true);
    await fetchData();
    setLoading(false);
  };

  return (
    <>
      <TableToolbar
        left={<input type="search" placeholder="Search..." />}
        right={
          <div style={{ display: 'flex', gap: '8px' }}>
            <IconButton
              icon={<RefreshCw />}
              aria-label="Refresh"
              onClick={handleRefresh}
              disabled={loading}
            />
            <Button leftIcon={<Plus />}>Add Item</Button>
          </div>
        }
      />
      <DataTable data={data} columns={columns} loading={loading} />
    </>
  );
}
```

## Best Practices

### 1. Show Bulk Actions When Selected

```tsx
// ✅ Good - conditional toolbar content
left={
  selected.length > 0 ? (
    <BulkActions selected={selected} />
  ) : (
    <SearchAndFilters />
  )
}

// ❌ Bad - always showing both
left={
  <>
    <BulkActions />
    <SearchAndFilters />
  </>
}
```

### 2. Group Related Actions

```tsx
// ✅ Good - grouped actions
right={
  <div style={{ display: 'flex', gap: '8px' }}>
    <Button variant="ghost">Export</Button>
    <Button variant="ghost">Print</Button>
    <Button>Add Item</Button>
  </div>
}

// ❌ Bad - scattered actions
right={
  <>
    <Button>Add Item</Button>
    <Button variant="ghost">Export</Button>
  </>
}
```

### 3. Use Appropriate Input Sizes

```tsx
// ✅ Good - reasonable search width
<input
  type="search"
  placeholder="Search..."
  style={{ width: '300px' }}
/>

// ❌ Bad - too wide
<input
  type="search"
  style={{ width: '100%' }}
/>
```

### 4. Provide Clear Labels

```tsx
// ✅ Good - clear placeholder
<input
  type="search"
  placeholder="Search by name or email..."
/>

// ❌ Bad - vague
<input type="search" placeholder="Search..." />
```

## Accessibility

The TableToolbar is accessible:

- **Keyboard**: All controls are keyboard accessible
- **Labels**: Inputs have proper labels or placeholders
- **Focus**: Clear focus indicators
- **Screen Readers**: Proper ARIA labels
