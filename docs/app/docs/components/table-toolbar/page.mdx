# Table Toolbar

A toolbar component designed to sit above a data table, handling title, actions, and selection states.

## Overview

The Table Toolbar provides a standardized header for your tables. It automatically switches context when items are selected, allowing for clear bulk action presentation.

## Advanced Usage

### Selection Mode

When `selectedCount` is greater than 0, the toolbar switches to a selection context, showing bulk actions instead of the defaults.

<LiveCodeBlock>
    <LivePreview>
        <Flex direction="column" gap="4">
            <div className="border rounded-t-lg">
                <TableToolbar
                    title="Products"
                    selectedCount={0}
                    rightContent={<Button size="sm" variant="secondary">Filter</Button>}
                />
            </div>
            <div className="border rounded-t-lg">
                <TableToolbar
                    title="Products"
                    selectedCount={3}
                    bulkActions={
                        <Flex gap="2">
                            <Button size="sm" variant="danger">Delete</Button>
                            <Button size="sm" variant="secondary">Archive</Button>
                        </Flex>
                    }
                />
            </div>
        </Flex>
    </LivePreview>
    <LiveSource
        code={`import { TableToolbar, Button, Flex } from '@oxygenix-ui/ui';

export default function SelectionDemo() {
  return (
    <Flex direction="column" gap="4">
      {/* Default State */}
      <div className="border rounded-t-lg">
        <TableToolbar
            title="Products"
            selectedCount={0}
            rightContent={<Button size="sm" variant="secondary">Filter</Button>}
        />
      </div>

      {/* Selection State */}
      <div className="border rounded-t-lg">
        <TableToolbar
            title="Products"
            selectedCount={3}
            bulkActions={
                <Flex gap="2">
                    <Button size="sm" variant="danger">Delete</Button>
                    <Button size="sm" variant="secondary">Archive</Button>
                </Flex>
            }
        />
      </div>
    </Flex>
  );
}`}
        language="tsx"
    />
</LiveCodeBlock>

## Accessibility

- **Heading**: Renders the title as an `h3` by default.
- **Context support**: Visually differentiates between "view" mode and "action" mode for selected items.

## Props

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `title` | `string` | - | The title of the table |
| `selectedCount` | `number` | `0` | Number of selected items |
| `leftContent` | `ReactNode` | - | Content to display on the left (e.g. filters) |
| `rightContent` | `ReactNode` | - | Content to display on the right (e.g. actions) |
| `bulkActions` | `ReactNode` | - | Actions shown when `selectedCount > 0` |
| `className` | `string` | - | Additional CSS class |

## Common Mistakes

### Forgetting Bulk Actions

If you pass `selectedCount` but don't provide `bulkActions`, the toolbar might look empty or broken in selection mode. Always categorize what users can do with the selection.
