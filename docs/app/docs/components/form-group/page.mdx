# FormGroup

Component for logically grouping related form fields, essential for organizing large forms and improving accessibility.

## Installation

```bash
npm install @oxygenix-ui/forms
```

## Basic Usage

```tsx
import { Form, Field, FieldGroup } from '@oxygenix-ui/forms';

function UserForm() {
  return (
    <Form onSubmit={handleSubmit}>
      <FieldGroup legend="Personal Information">
        <Field name="firstName" label="First Name" type="text" required />
        <Field name="lastName" label="Last Name" type="text" required />
        <Field name="email" label="Email" type="email" required />
      </FieldGroup>

      <FieldGroup legend="Address">
        <Field name="street" label="Street" type="text" required />
        <Field name="city" label="City" type="text" required />
        <Field name="zip" label="ZIP Code" type="text" required />
      </FieldGroup>

      <button type="submit">Submit</button>
    </Form>
  );
}
```

## Features

### Semantic Grouping

Uses `<fieldset>` and `<legend>` for semantic HTML.

```tsx
<FieldGroup legend="Contact Information">
  <Field name="phone" label="Phone" type="tel" />
  <Field name="email" label="Email" type="email" />
</FieldGroup>
```

### With Description

Add context to field groups.

```tsx
<FieldGroup 
  legend="Security Settings"
  description="Configure your account security preferences"
>
  <Field name="twoFactor" label="Enable 2FA" type="checkbox" />
  <Field name="loginAlerts" label="Login alerts" type="checkbox" />
</FieldGroup>
```

### Nested Groups

Group related sections hierarchically.

```tsx
<Form onSubmit={handleSubmit}>
  <FieldGroup legend="Account Details">
    <Field name="username" label="Username" type="text" required />
    <Field name="email" label="Email" type="email" required />
    
    <FieldGroup legend="Password">
      <Field name="password" label="Password" type="password" required />
      <Field name="confirmPassword" label="Confirm Password" type="password" required />
    </FieldGroup>
  </FieldGroup>
</Form>
```

## API Reference

### FieldGroup

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `legend` | `ReactNode` | - | Group legend (heading) |
| `description` | `string` | - | Group description |
| `children` | `ReactNode` | Required | Child fields |
| `className` | `string` | - | Additional CSS class |

## Accessibility

The FieldGroup component ensures:

- **Semantic HTML**: Uses `<fieldset>` and `<legend>`
- **Screen Readers**: Groups announced as related fields
- **Keyboard Navigation**: Proper tab order maintained
- **Visual Grouping**: Clear visual separation

## Best Practices

### 1. Group Related Fields

```tsx
// ✅ Good - logical grouping
<FieldGroup legend="Contact Information">
  <Field name="email" label="Email" type="email" />
  <Field name="phone" label="Phone" type="tel" />
</FieldGroup>

// ❌ Bad - unrelated fields
<FieldGroup legend="Information">
  <Field name="email" label="Email" type="email" />
  <Field name="favoriteColor" label="Favorite Color" type="text" />
</FieldGroup>
```

### 2. Use Descriptive Legends

```tsx
// ✅ Good - clear legend
<FieldGroup legend="Shipping Address">
  {/* fields */}
</FieldGroup>

// ❌ Bad - vague legend
<FieldGroup legend="Section 1">
  {/* fields */}
</FieldGroup>
```

### 3. Add Descriptions for Context

```tsx
// ✅ Good - helpful description
<FieldGroup 
  legend="Privacy Settings"
  description="Control who can see your information"
>
  {/* fields */}
</FieldGroup>

// ❌ Bad - no context
<FieldGroup legend="Privacy Settings">
  {/* fields */}
</FieldGroup>
```

### 4. Don't Over-Group

```tsx
// ✅ Good - meaningful groups
<FieldGroup legend="Personal Info">
  <Field name="name" />
  <Field name="email" />
</FieldGroup>

// ❌ Bad - single field in group
<FieldGroup legend="Name">
  <Field name="name" />
</FieldGroup>
```

## Styling

The FieldGroup uses CSS modules. Customize via className:

```tsx
<FieldGroup legend="Contact" className="custom-group">
  {/* fields */}
</FieldGroup>
```

```css
  font-weight: 600;
  color: #333;
}
```
