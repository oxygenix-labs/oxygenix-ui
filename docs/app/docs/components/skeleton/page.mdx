# Skeleton

Layout-aware loading placeholder component with smooth shimmer animation. Available in 5 variants for different content types.

## Installation

```bash
npm install @oxygenix-ui/ui
```

## Basic Usage

```tsx
import { Skeleton } from '@oxygenix-ui/ui';

function LoadingCard() {
  return (
    <div>
      <Skeleton variant="title" />
      <Skeleton variant="text" count={3} />
    </div>
  );
}
```

## Variants

### Text

For body text and paragraphs.

```tsx
<Skeleton variant="text" width="100%" />
<Skeleton variant="text" width="80%" />
<Skeleton variant="text" width="60%" />
```

### Title

For headings and titles.

```tsx
<Skeleton variant="title" width="200px" />
```

### Avatar

For circular profile pictures.

```tsx
<Skeleton variant="avatar" width={40} height={40} />
```

### Rectangle

For images, cards, and rectangular content.

```tsx
<Skeleton variant="rect" width="100%" height={200} />
```

### Circle

For circular elements like badges or icons.

```tsx
<Skeleton variant="circle" width={24} height={24} />
```

## API Reference

### Skeleton

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `variant` | `'text' \| 'title' \| 'avatar' \| 'rect' \| 'circle'` | `'text'` | Skeleton variant |
| `width` | `string \| number` | - | Width (px or %) |
| `height` | `string \| number` | - | Height (px or %) |
| `borderRadius` | `string \| number` | - | Border radius |
| `count` | `number` | `1` | Number of skeleton lines |
| `className` | `string` | - | Additional CSS class |
| `style` | `CSSProperties` | - | Inline styles |

## Best Practices

### 1. Match Content Layout

```tsx
// ✅ Good - skeleton matches actual content
<Skeleton variant="avatar" width={48} height={48} />
<Skeleton variant="title" width="200px" />
<Skeleton variant="text" count={2} />

// ❌ Bad - doesn't match layout
<Skeleton variant="rect" width="100%" height={500} />
```

### 2. Use Appropriate Variants

```tsx
// ✅ Good - correct variants
<Skeleton variant="avatar" /> // for profile pic
<Skeleton variant="title" />  // for heading
<Skeleton variant="text" />   // for paragraph

// ❌ Bad - wrong variants
<Skeleton variant="rect" />   // for text
<Skeleton variant="text" />   // for image
```

### 3. Vary Text Widths

```tsx
// ✅ Good - natural text variation
<Skeleton variant="text" width="100%" />
<Skeleton variant="text" width="90%" />
<Skeleton variant="text" width="75%" />

// ❌ Bad - all same width
<Skeleton variant="text" width="100%" />
<Skeleton variant="text" width="100%" />
<Skeleton variant="text" width="100%" />
```

### 4. Use Count for Repeated Content

```tsx
// ✅ Good - use count prop
<Skeleton variant="text" count={5} />

// ❌ Bad - manual repetition
<Skeleton variant="text" />
<Skeleton variant="text" />
<Skeleton variant="text" />
<Skeleton variant="text" />
<Skeleton variant="text" />
```

## Animation

The Skeleton component includes a smooth shimmer animation by default:

- **Gradient**: Subtle light-to-dark gradient
- **Duration**: 1.5s animation loop
- **Direction**: Left to right shimmer
- **Performance**: GPU-accelerated

## Accessibility

The Skeleton component is accessible:

- **ARIA**: `aria-hidden="true"` to hide from screen readers
- **Loading State**: Use with proper loading announcements
- **Focus**: Not focusable (decorative only)

## Styling

Customize Skeleton using className or style:

```tsx
<Skeleton
  variant="rect"
  width="100%"
  height={200}
  className="custom-skeleton"
  style={{ borderRadius: '12px' }}
/>
```

```css
.custom-skeleton {
  background: linear-gradient(90deg, #f0f0f0 25%, #e0e0e0 50%, #f0f0f0 75%);
}
```
