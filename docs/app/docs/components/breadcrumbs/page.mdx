# Breadcrumbs

Displays a list of links indicating the current page's location within a navigational hierarchy.

## Overview

Breadcrumbs help users understand their location within a website and move back to parent categories.

## Import

<LiveCodeBlock>

## Basic Usage

Pass an array of `items` where each item has a `label`. Add an `href` to make an item clickable. The last item typically represents the current page and should not have an `href`.

import BreadcrumbsBasicDemo from './BreadcrumbsBasicDemo';
import BreadcrumbsAdvancedDemo from './BreadcrumbsAdvancedDemo';

## Accessibility

-   **Landmark**: The component uses a `<nav>` element with `aria-label="Breadcrumb"`.
-   **Current Page**: The last item (if it has no `href`) receives `aria-current="page"`.
-   **Separators**: Separators are hidden from screen readers using `aria-hidden="true"`.

## Props

### Breadcrumbs

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `items` | `BreadcrumbsItem[]` | **Required** | Array of breadcrumb items |
| `separator` | `ReactNode` | `/` | Visual separator between items |
| `className` | `string` | - | Additional CSS class names |

### BreadcrumbsItem

| Property | Type | Description |
| :--- | :--- | :--- |
| `label` | `ReactNode` | Text or component to display |
| `href` | `string` | URL for the link (renders `<a>` if present, `<span>` otherwise) |
| `onClick` | `() => void` | Optional click handler |

## Common Mistakes

### Adding href to Last Item

The last item in the breadcrumb trail represents the current page. It should generally not be a link (unless it links to a specific anchor on the page).

### Accessibility Labels

If using only icons for breadcrumb labels (e.g., a Home icon), ensure you provide screen reader context, though the `Breadcrumbs` component treats labels as visual content. Consider using `aria-label` or visually hidden text if the icon itself isn't semantic enough.
