# Badge

Small status descriptors for UI elements.

## Overview

Badges are used to highlight an item's status for quick recognition. They are commonly used for tags, counts, and status indicators.

## Basic Usage

The `Badge` component renders a small colored label. Use the `variant` prop to control the color.

import BadgeBasicDemo from './BadgeBasicDemo';
import BadgeAdvancedDemo from './BadgeAdvancedDemo';

    <LivePreview>
        <BadgeBasicDemo />

## Accessibility

-   **Semantic Content**: Badges generally contain text that is read by screen readers.
-   **Color Usage**: Ensure that color is not the only way information is conveyed. The text content (e.g., "Error", "Success") provides the primary semantic meaning.

## Props

### Badge

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `children` | `ReactNode` | - | The content to display inside the badge |
| `variant` | `'default' \| 'primary' \| 'success' \| 'warning' \| 'error' \| 'info'` | `'default'` | Visual color variant |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | Size of the badge |
| `dot` | `boolean` | `false` | Shows a small dot indicator (useful for status) |
| `className` | `string` | - | Additional CSS class names |
