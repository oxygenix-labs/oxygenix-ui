# Badge

Status indicator component with 6 variants, 3 sizes, and optional dot indicator. Perfect for active, pending, and archived states.

## Installation

```bash
npm install @oxygenix-ui/ui
```

## Basic Usage

```tsx
import { Badge } from '@oxygenix-ui/ui';

function MyComponent() {
  return <Badge>Active</Badge>;
}
```

## Variants

### Default

```tsx
<Badge variant="default">Default</Badge>
```

### Primary

```tsx
<Badge variant="primary">Primary</Badge>
```

### Success

```tsx
<Badge variant="success">Active</Badge>
```

### Warning

```tsx
<Badge variant="warning">Pending</Badge>
```

### Error

```tsx
<Badge variant="error">Failed</Badge>
```

### Info

```tsx
<Badge variant="info">New</Badge>
```

## Sizes

### Small

```tsx
<Badge size="sm">Small</Badge>
```

### Medium (Default)

```tsx
<Badge size="md">Medium</Badge>
```

### Large

```tsx
<Badge size="lg">Large</Badge>
```

## Features

### Dot Indicator

Add a dot for live status.

```tsx
<Badge variant="success" dot>Online</Badge>
<Badge variant="error" dot>Offline</Badge>
```

## API Reference

### Badge

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `variant` | `'default' \| 'primary' \| 'success' \| 'warning' \| 'error' \| 'info'` | `'default'` | Badge variant |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | Badge size |
| `children` | `ReactNode` | Required | Badge content |
| `dot` | `boolean` | `false` | Show dot indicator |
| `className` | `string` | - | Additional CSS class |

## Examples

### User Status

```tsx
function UserStatus({ status }) {
  const statusConfig = {
    online: { variant: 'success', label: 'Online', dot: true },
    away: { variant: 'warning', label: 'Away', dot: true },
    offline: { variant: 'default', label: 'Offline', dot: false },
  };

  const config = statusConfig[status];

  return (
    <Badge variant={config.variant} dot={config.dot}>
      {config.label}
    </Badge>
  );
}
```

### Order Status

```tsx
function OrderStatus({ status }) {
```

### Notification Count

```tsx
function NotificationBadge({ count }) {
  if (count === 0) return null;

  return (
    <Badge variant="error" size="sm">
      {count > 99 ? '99+' : count}
    </Badge>
  );
}
```

## Best Practices

### 1. Use Semantic Variants

```tsx
// ✅ Good - semantic colors
<Badge variant="success">Active</Badge>
<Badge variant="warning">Pending</Badge>
<Badge variant="error">Failed</Badge>

// ❌ Bad - wrong colors
<Badge variant="error">Active</Badge>
<Badge variant="success">Failed</Badge>
```

### 2. Keep Text Concise

```tsx
// ✅ Good - short and clear
<Badge variant="success">Active</Badge>
<Badge variant="warning">Pending</Badge>

// ❌ Bad - too verbose
<Badge variant="success">Currently Active</Badge>
<Badge variant="warning">Pending Approval</Badge>
```

### 3. Use Dot for Live Status

```tsx
// ✅ Good - dot indicates live/active
<Badge variant="success" dot>Online</Badge>
<Badge variant="error" dot>LIVE</Badge>

// ❌ Bad - dot for static status
<Badge variant="default" dot>Archived</Badge>
```

### 4. Choose Appropriate Size

```tsx
// ✅ Good - small for inline use
<span>User <Badge size="sm">Admin</Badge></span>

// ✅ Good - large for prominent display
<Badge size="lg" variant="error">URGENT</Badge>

// ❌ Bad - large for inline use
<span>User <Badge size="lg">Admin</Badge></span>
```

## Use Cases

### Perfect for:
- ✅ User status (online/offline)
- ✅ Order status
- ✅ Task priority
- ✅ Feature flags (new, beta)
- ✅ User roles
- ✅ Notification counts

### Not recommended for:
- ❌ Long text (use Text or Label)
- ❌ Interactive elements (use Button)
- ❌ Form validation (use field errors)

## Accessibility

The Badge component is accessible:

- **Semantic HTML**: Uses `<span>` element
- **Color + Text**: Not relying on color alone
- **Contrast**: Sufficient color contrast
