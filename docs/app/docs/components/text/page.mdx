# Text

Semantic typography component that provides consistent text styling across your application.

## Overview

The Text component is the fundamental building block for all typography in your application. It enforces specific variants and weights to ensure consistency and readability.

## Accessibility

- **Semantic HTML**: By using the `as` prop, you can ensure your text uses the correct HTML tag (e.g., `<label>`, `<p>`, `<span>`) for screen readers.
- **Contrast**: The built-in variants (especially `muted`) are designed to meet standard contrast ratios.
- **Scaling**: Text sizes are defined in relative units to respect user browser settings.

## Props

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `variant` | `'body' \| 'muted' \| 'caption' \| 'small' \| 'large'` | `'body'` | Text style variant |
| `weight` | `'normal' \| 'medium' \| 'bold'` | `'normal'` | Font weight |
| `as` | `ElementType` | `'p'` | Underlying HTML element to render |
| `children` | `ReactNode` | - | Text content |
| `className` | `string` | - | Additional CSS class |

## Common Mistakes

### Using arbitrary styles

Avoid using the `className` prop to set font sizes or colors directly. Use `variant` and `weight` props to maintain consistency with the design system.

### Incorrect HTML semantics

Don't use `Text` with `as="div"` for everything. Use specific tags like `p`, `span`, or `label` via the `as` prop to ensure your application is accessible.
