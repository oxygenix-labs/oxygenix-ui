# Text

Semantic typography component that provides consistent text styling across your application. Prevents arbitrary font sizes and weights.

## Installation

```bash
npm install @oxygenix-ui/ui
```

## Basic Usage

```tsx
import { Text } from '@oxygenix-ui/ui';

function App() {
  return (
    <Text>This is body text with consistent styling.</Text>
  );
}
```

## Variants

The Text component supports five semantic variants.

### Body (Default)

Standard body text for paragraphs and general content.

```tsx
<Text variant="body">
  This is standard body text used for paragraphs and general content.
</Text>
```

### Muted

Subdued text for secondary information.

```tsx
<Text variant="muted">
  This is muted text for less important information.
</Text>
```

### Caption

Small text for captions, labels, and metadata.

```tsx
<Text variant="caption">
  Posted 2 hours ago
</Text>
```

### Small

Smaller text for fine print or disclaimers.

```tsx
<Text variant="small">
  * Terms and conditions apply
</Text>
```

### Large

Larger text for emphasis or lead paragraphs.

```tsx
<Text variant="large">
  This is a lead paragraph with larger text for emphasis.
</Text>
```

## Font Weight

Control the font weight independently of the variant.

```tsx
<Text weight="normal">Normal weight text</Text>
<Text weight="medium">Medium weight text</Text>
<Text weight="bold">Bold weight text</Text>
```

## Custom HTML Element

Use the `as` prop to render as a different HTML element while maintaining the styling.

```tsx
<Text as="span">Inline text</Text>
<Text as="div">Block text</Text>
<Text as="label">Form label</Text>
```

## API Reference

### Text

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `variant` | `'body' \| 'muted' \| 'caption' \| 'small' \| 'large'` | `'body'` | Text variant |
| `weight` | `'normal' \| 'medium' \| 'bold'` | `'normal'` | Font weight |
| `as` | `ElementType` | `'p'` | HTML element to render |
| `children` | `ReactNode` | Required | Text content |
| `className` | `string` | - | Additional CSS class |

All standard HTML element attributes are supported based on the `as` prop.

## Examples

### Article Content

```tsx
function Article() {
  return (
    <article>
      <Text variant="large" weight="medium">
        This is the lead paragraph that introduces the article with
        larger, medium-weight text to draw attention.
      </Text>

      <Text variant="body">
        This is the main body content of the article. It uses the
        default body variant for optimal readability.
      </Text>

      <Text variant="muted">

      </Text>
    </article>

```

### Form Labels and Help Text

```tsx

  return (
    <div>
      <Text as="label" weight="medium" htmlFor="email">

      </Text>

        We'll never share your email with anyone else.
      </Text>
    </div>

```

### Card Metadata

```tsx

      <Text variant="body" weight="medium">

      </Text>
      <Text variant="caption">
```

## Best Practices

### 1. Use Semantic Variants

Choose variants based on content hierarchy:

```tsx
// ✅ Good - semantic usage
<Text variant="large">Introduction paragraph</Text>
<Text variant="body">Main content</Text>
<Text variant="muted">Secondary information</Text>
<Text variant="caption">Metadata</Text>

// ❌ Bad - arbitrary styling
<Text style={{ fontSize: '18px' }}>Some text</Text>
<Text style={{ color: '#666' }}>Other text</Text>
```

### 2. Combine Variant and Weight

Use variant for size/color and weight for emphasis:

```tsx
// ✅ Good
<Text variant="body" weight="medium">Important body text</Text>
<Text variant="muted" weight="bold">Emphasized secondary text</Text>

// ❌ Bad - using variant for emphasis
<Text variant="large">Not actually large content</Text>
```

### 3. Use Appropriate HTML Elements

Match the `as` prop to the semantic meaning:

```tsx
// ✅ Good
<Text as="label" htmlFor="name">Name</Text>
<Text as="span">Inline text</Text>
<Text as="p">Paragraph</Text>

// ❌ Bad - wrong semantics
<Text as="div" htmlFor="name">Name</Text> {/* labels should be <label> */}
```

### 4. Maintain Hierarchy

Use variants to establish clear visual hierarchy:

```tsx
// ✅ Good - clear hierarchy
<Text variant="large" weight="medium">Main heading</Text>
<Text variant="body">Body content</Text>
<Text variant="caption">Additional info</Text>

// ❌ Bad - no hierarchy
<Text>Everything</Text>
<Text>Looks</Text>
<Text>The same</Text>
```

## Typography Scale

The Text component follows a consistent typography scale:

- **Large**: 18px / 1.5 line-height
- **Body**: 14px / 1.6 line-height
- **Muted**: 14px / 1.6 line-height (reduced opacity)
- **Caption**: 12px / 1.4 line-height
- **Small**: 11px / 1.4 line-height

## Accessibility

The Text component is accessible by default:

- **Semantic HTML**: Uses appropriate elements via `as` prop
- **Readable Contrast**: Muted variant maintains WCAG AA contrast
- **Line Height**: Optimized for readability
- **Font Size**: Minimum 11px for legibility

## Styling

Customize Text using className:

```tsx
<Text className="custom-text">
  Custom styled text
</Text>
```

```css
.custom-text {
  --text-color: #custom-color;
  --text-line-height: 1.8;
}
```
