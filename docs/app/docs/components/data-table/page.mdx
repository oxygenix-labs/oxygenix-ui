# DataTable

Enterprise-grade data table component with sortable columns, pagination (client & server-side), row selection, custom cell rendering, and full keyboard accessibility.

## Installation

```bash
npm install @oxygenix-ui/data
```

## Basic Usage

```tsx
import { DataTable } from '@oxygenix-ui/data';

const columns = [
  { id: 'name', header: 'Name', accessor: 'name', sortable: true },
  { id: 'email', header: 'Email', accessor: 'email', sortable: true },
  { id: 'role', header: 'Role', accessor: 'role' },
];

const data = [
  { id: '1', name: 'John Doe', email: 'john@example.com', role: 'Admin' },
  { id: '2', name: 'Jane Smith', email: 'jane@example.com', role: 'Editor' },
];

function UserTable() {
  return <DataTable data={data} columns={columns} />;
}
```

## Features

### Sortable Columns

Click column headers to sort ascending/descending.

```tsx
<DataTable
  data={users}
  columns={[
    { id: 'name', header: 'Name', accessor: 'name', sortable: true },
    { id: 'email', header: 'Email', accessor: 'email', sortable: true },
    { id: 'createdAt', header: 'Created', accessor: 'createdAt', sortable: true },
  ]}
  sorting={{
    enabled: true,
    mode: 'single', // or 'multi' for multiple columns
  }}
/>
```

### Pagination

Client-side and server-side pagination support.

```tsx
// Client-side pagination
<DataTable
  data={users}
  columns={columns}
  pagination={{
    enabled: true,
    pageSize: 10,
    pageSizeOptions: [10, 25, 50, 100],
    showPageSizeSelector: true,
  }}
/>

// Server-side pagination
<DataTable
  data={currentPageData}
  columns={columns}
  pagination={{
    enabled: true,
    pageSize: 10,
    currentPage: page,
    onPageChange: setPage,
  }}
  serverSide={{
    totalRows: totalCount,
    onFetchData: async (params) => {
      const result = await fetchUsers(params);
      return { data: result.users, totalRows: result.total };
    },
  }}
/>
```

### Row Selection

Single or multi-row selection with select-all.

```tsx
function SelectableTable() {
  const [selected, setSelected] = useState([]);

  return (
    <DataTable
      data={users}
      columns={columns}
      selection={{
        mode: 'multi', // or 'single'
        selectedRows: selected,
        onSelectionChange: (ids, rows) => {
          setSelected(ids);
          console.log('Selected rows:', rows);
        },
        showSelectAll: true,
      }}
    />
  );
}
```

### Custom Cell Rendering

Render custom content in cells (badges, buttons, etc.).

```tsx
<DataTable
  data={users}
  columns={[
    { id: 'name', header: 'Name', accessor: 'name' },
    {
      id: 'status',
      header: 'Status',
      accessor: 'status',
      cell: ({ value }) => (
        <span className={`badge badge-${value}`}>
          {value}
        </span>
      ),
    },
    {
      id: 'actions',
      header: 'Actions',
      cell: ({ row }) => (
        <div>
          <button onClick={() => editUser(row.id)}>Edit</button>
          <button onClick={() => deleteUser(row.id)}>Delete</button>
        </div>
      ),
    },
  ]}
/>
```

## API Reference

### DataTable

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `data` | `T[]` | Required | Table data |
| `columns` | `Column<T>[]` | Required | Column definitions |
| `sorting` | `SortingConfig` | - | Sorting configuration |
| `pagination` | `PaginationConfig` | - | Pagination configuration |
| `selection` | `SelectionConfig<T>` | - | Selection configuration |
| `serverSide` | `ServerSideConfig<T>` | - | Server-side mode |
| `onRowClick` | `(row: T, event: MouseEvent) => void` | - | Row click handler |
| `rowClassName` | `(row: T) => string` | - | Custom row class |
| `slots` | `SlotsConfig<T>` | - | Custom slots |
| `loading` | `boolean` | `false` | Loading state |
| `error` | `Error` | - | Error state |
| `getRowId` | `(row: T) => string` | - | Get row ID function |

### Column

| Property | Type | Description |
|----------|------|-------------|
| `id` | `string` | Unique column ID |
| `header` | `ReactNode \| (context) => ReactNode` | Column header |
| `accessor` | `keyof T \| (row: T) => any` | Data accessor |
| `cell` | `(context: CellContext<T>) => ReactNode` | Custom cell renderer |
| `width` | `number \| string` | Column width |
| `sortable` | `boolean` | Whether sortable |
| `align` | `'left' \| 'center' \| 'right'` | Text alignment |

### SortingConfig

| Property | Type | Description |
|----------|------|-------------|
| `enabled` | `boolean` | Enable sorting |
| `mode` | `'single' \| 'multi'` | Sort mode |
| `sortState` | `SortingState` | Current sort state |
| `onSortChange` | `(state: SortingState) => void` | Sort change handler |

### PaginationConfig

| Property | Type | Description |
|----------|------|-------------|
| `enabled` | `boolean` | Enable pagination |
| `pageSize` | `number` | Page size |
| `pageSizeOptions` | `number[]` | Page size options |
| `currentPage` | `number` | Current page (1-indexed) |
| `onPageChange` | `(page: number) => void` | Page change handler |
| `showPageSizeSelector` | `boolean` | Show page size selector |

### SelectionConfig

| Property | Type | Description |
|----------|------|-------------|
| `mode` | `'single' \| 'multi'` | Selection mode |
| `selectedRows` | `string[]` | Selected row IDs |
| `onSelectionChange` | `(ids: string[], rows: T[]) => void` | Selection handler |
| `showSelectAll` | `boolean` | Show select all checkbox |
| `isRowSelectable` | `(row: T) => boolean` | Row selectable check |

### Server-Side Table

```tsx
function ServerSideTable() {
  const [data, setData] = useState([]);
  const [totalRows, setTotalRows] = useState(0);
  const [loading, setLoading] = useState(false);

  const fetchData = async (params) => {
    setLoading(true);
    try {
      const response = await api.getUsers({
        page: params.page,
        pageSize: params.pageSize,
        sortBy: params.sorting?.[0]?.column,
        sortDir: params.sorting?.[0]?.direction,
      });
      setData(response.data);
      setTotalRows(response.total);
      return { data: response.data, totalRows: response.total };
    } finally {
      setLoading(false);
    }
  };

  return (
    <DataTable
      data={data}
      columns={columns}
      loading={loading}
      serverSide={{
        totalRows,
        onFetchData: fetchData,
      }}
      pagination={{
        enabled: true,
        pageSize: 25,
      }}
      sorting={{
        enabled: true,
      }}
    />
  );
}
```

## Keyboard Accessibility

The DataTable is fully keyboard accessible:

- **Tab**: Navigate between interactive elements
- **Enter/Space**: Activate buttons and checkboxes
- **Arrow Keys**: Navigate cells (when focused)
- **Shift + Click**: Multi-select rows

## Best Practices

### 1. Provide Unique Row IDs

```tsx
// ✅ Good
<DataTable
  data={users}
  columns={columns}
  getRowId={(row) => row.id}
/>

// ❌ Bad - relying on array index
<DataTable data={users} columns={columns} />
```

### 2. Use Server-Side for Large Datasets

```tsx
// ✅ Good - server-side for 1000+ rows
<DataTable
  data={currentPage}
  columns={columns}
  serverSide={{ totalRows, onFetchData }}
/>

// ❌ Bad - client-side for large data
<DataTable data={allThousandRows} columns={columns} />
```

### 3. Memoize Columns

```tsx
// ✅ Good
const columns = useMemo(() => [
  { id: 'name', header: 'Name', accessor: 'name' },
], []);

// ❌ Bad - recreates on every render
const columns = [
  { id: 'name', header: 'Name', accessor: 'name' },
];
```
