# Checkbox

A control element that allows the user to select one or more items from a set.

## Overview

The Checkbox component is used for binary choices, or selecting multiple options from a list. It supports an indeterminate state for "select all" functionality.

## Advanced Usage

### Indeterminate State

Use the `indeterminate` prop to show a state that is neither checked nor unchecked, often used in a "Select All" checkbox.

## Accessibility

- **Labels**: Always provide a `label` prop or use `aria-label` if no visible label is present. The component automatically associates the label with the input.
- **Keyboard interaction**: Space bar toggles the state.

## Props

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `label` | `string` | - | The label text next to the checkbox |
| `indeterminate` | `boolean` | `false` | Sets visual indeterminate state |
| `checked` | `boolean` | - | Checked state (controlled) |
| `onChange` | `(e) => void` | - | Change handler |
| `className` | `string` | - | Additional CSS class |
| ... | `InputHTMLAttributes` | - | Standard input attributes |

## Common Mistakes

### Missing Label

Using a checkbox without a label (unlabeled) makes it hard to click and impossible for screen reader users to understand. Always provide a label.

### Confusing Radio buttons and Checkboxes

Use Checkboxes when users can select multiple items. Use Radio buttons when users must select exactly one item.
