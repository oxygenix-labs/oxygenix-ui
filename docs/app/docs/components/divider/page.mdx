# Divider

Subtle separator component for creating visual divisions in dense layouts. Supports horizontal and vertical orientations.

## Installation

```bash
npm install @oxygenix-ui/ui
```

## Basic Usage

```tsx
import { Divider } from '@oxygenix-ui/ui';

function App() {
  return (
    <div>
      <p>Content above</p>
      <Divider />
      <p>Content below</p>
    </div>
  );
}
```

## Orientation

### Horizontal (Default)

Horizontal dividers separate content vertically.

```tsx
<div>
  <p>Section 1</p>
  <Divider orientation="horizontal" />
  <p>Section 2</p>
</div>
```

### Vertical

Vertical dividers separate content horizontally.

```tsx
<div style={{ display: 'flex', alignItems: 'center', gap: '16px' }}>
  <span>Item 1</span>
  <Divider orientation="vertical" />
  <span>Item 2</span>
  <Divider orientation="vertical" />
  <span>Item 3</span>
</div>
```

## Styles

### Solid (Default)

Standard solid line divider.

```tsx
<Divider />
```

### Dashed

Dashed line for subtle separation.

```tsx
<Divider dashed />
```

## API Reference

### Divider

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `orientation` | `'horizontal' \| 'vertical'` | `'horizontal'` | Divider orientation |
| `dashed` | `boolean` | `false` | Use dashed style |
| `className` | `string` | - | Additional CSS class |

All standard HTML `<hr>` attributes are supported.

## Accessibility

The Divider component is fully accessible:

- **Semantic HTML**: Uses `<hr>` element
- **ARIA Role**: `role="separator"` for assistive technologies
- **Orientation**: `aria-orientation` attribute for screen readers

## Best Practices

### 1. Use for Visual Separation

Dividers create visual breaks between related content:

```tsx
// ✅ Good - separating distinct sections
<section>Content 1</section>
<Divider />
<section>Content 2</section>

// ❌ Bad - overusing dividers
<p>Line 1</p>
<Divider />
<p>Line 2</p>
<Divider />
<p>Line 3</p>
```

### 2. Choose Appropriate Orientation

Use vertical dividers for horizontal layouts:

```tsx
// ✅ Good - vertical for flex row
<div style={{ display: 'flex' }}>
  <span>Item 1</span>
  <Divider orientation="vertical" />
  <span>Item 2</span>
</div>

// ❌ Bad - horizontal in flex row
<div style={{ display: 'flex' }}>
  <span>Item 1</span>
  <Divider orientation="horizontal" />
  <span>Item 2</span>
</div>
```

### 3. Use Dashed for Subtle Separation

Dashed dividers are less prominent:

```tsx
// ✅ Good - dashed for related content
<div>
  <Text>Primary content</Text>
  <Divider dashed />
  <Text variant="muted">Related metadata</Text>
</div>

// ✅ Good - solid for distinct sections
<section>Section 1</section>
<Divider />
<section>Section 2</section>
```

### 4. Maintain Consistent Spacing

Add consistent spacing around dividers:

```tsx
// ✅ Good - consistent spacing
<div style={{ display: 'flex', flexDirection: 'column', gap: '16px' }}>
  <section>Content 1</section>
  <Divider />
  <section>Content 2</section>
</div>

// ❌ Bad - inconsistent spacing
<div>
  <section style={{ marginBottom: '8px' }}>Content 1</section>
  <Divider />
  <section style={{ marginTop: '24px' }}>Content 2</section>
</div>
```

## When to Use

### Use Divider when:
- ✅ Separating distinct content sections
- ✅ Creating visual breaks in dense layouts
- ✅ Grouping related items in menus or lists
- ✅ Separating toolbar button groups

### Don't use Divider when:
- ❌ Whitespace alone would suffice
- ❌ Content is already visually distinct
- ❌ Overusing creates visual clutter
