# Divider

A separator component that creates a visual distinction between content.

## Overview

Dividers are used to group adjacent related content or separate disparate content. They provide a clear visual break in the layout.

## Advanced Usage

Use the `orientation` prop to create a vertical separator. Ensure the parent container has a defined height or is a flex container.

## Accessibility

- **Role**: The component renders a semantic `<hr>` tag which has an implicit `separator` role.
- **Orientation**: If `orientation="vertical"` is set, the component adds `aria-orientation="vertical"` to correct the accessibility tree.

## Props

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `orientation` | `'horizontal' \| 'vertical'` | `'horizontal'` | The orientation of the divider |
| `dashed` | `boolean` | `false` | Whether the divider should have a dashed style |
| `className` | `string` | - | Additional CSS class |

## Common Mistakes

### Using border instead of Divider

While borders can separate content, `Divider` provides semantic meaning and consistent styling specifically for separating disparate content sections.

### Vertical Divider without height

Vertical dividers need a height to be visible. Either set a height on the Divider itself or place it in a container with a defined height (like a Flex container with `align="center"` or `stretch`).
