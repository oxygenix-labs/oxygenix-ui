# Grid

A responsive grid layout system that simplifies creating column-based layouts without the complexity of raw CSS Grid.

## Overview

The `Grid` component provides a straightforward way to create responsive grid layouts. It supports defining column counts for different breakpoints (mobile, tablet, desktop) and managing gaps between items.

## Basic Usage

Create a grid with a fixed number of columns using the `cols` prop.

import GridBasicDemo from './GridBasicDemo';
import GridResponsiveDemo from './GridResponsiveDemo';

## Responsive Usage

You can control the number of columns at different breakpoints using `colsSm` (mobile) and `colsMd` (tablet).

## Accessibility

-   **Structure**: `Grid` renders a `<div>` with `display: grid`.
-   **Reading Order**: Screen readers follow the DOM order, which matches the visual order of the grid cells (left-to-right, top-to-bottom).
-   **Semantics**: Like `Stack`, `Grid` is a layout utility. Use semantic containers within grid cells if needed.

## Props

### Grid

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `children` | `ReactNode` | **Required** | Grid items |
| `cols` | `1 \| 2 \| 3 \| 4 \| 6 \| 12` | `12` | Columns on desktop (default) |
| `colsMd` | `1 \| 2 \| 3 \| 4 \| 6 \| 12` | - | Columns on tablet (max-width: 768px) |
| `colsSm` | `1 \| 2 \| 3 \| 4 \| 6 \| 12` | - | Columns on mobile (max-width: 640px) |
| `gap` | `1 \| 2 \| 3 \| 4 \| 5 \| 6 \| 8` | `4` | Spacing between items (mapped to design tokens) |
| `className` | `string` | - | Additional CSS class names |
| `style` | `CSSProperties` | - | Inline styles |

## Common Mistakes

### Direct Children

The `Grid` component applies layout to its *direct children*. Wrappers or fragments around children might disrupt the grid layout if not handled carefully (though generally `Fragment` is fine as it doesn't render a DOM node, `Grid` styles target direct DOM children).

### Over-nesting

Avoid nesting grids deeply if a single grid with `colSpan` (if supported via CSS classes on children) could achieve the same layout. Note: The current `Grid` component focuses on uniform columns. For irregular spans, you might need custom CSS or a more complex component.
