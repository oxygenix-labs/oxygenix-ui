# Icon Button

Compact button for icons only - perfect for toolbars, tables, and dense UIs.

## Overview

The IconButton component renders a button with an icon and no text. It effectively communicates actions while saving space.

## Accessibility

- **Required `aria-label`**: Since there is no visible text, you must provide an `aria-label` prop to describe the button's action for screen readers.
- Renders a native `<button>` element.
- Supports keyboard focus and interaction.

## Props

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `icon` | `ReactNode` | - | The icon element to render |
| `aria-label` | `string` | - | **Required**. Accessible label for the button |
| `variant` | `'primary' \| 'secondary' \| 'ghost' \| 'danger' \| 'solid' \| 'soft'` | `'primary'` | Visual style of the button |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | Size of the button |
| `disabled` | `boolean` | `false` | Disables the button |
| `className` | `string` | - | Additional CSS class |

## Common Mistakes

### Missing aria-label

Always provide an `aria-label`. Without it, users relying on screen readers won't know what action the button performs.

### Using for text

Don't use IconButton if you need to display text. Use the standard `Button` component with an icon prop instead.
