# Empty State

A component to display when a list or table has no data.

## Overview

The Empty State component communicates to the user that there is no content to display. It supports icons, titles, descriptions, and call-to-action buttons.

## Advanced Usage

## Accessibility

- **Landmark**: Often acts as the main content area when data is missing.
- **Focus**: If an action is present, ensure it is keyboard accessible (handled by `Button`).

## Props

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `title` | `string` | **Required** | The main heading content |
| `description` | `string` | - | Secondary explanation text |
| `icon` | `ReactNode` | - | Illustration or icon above the title |
| `action` | `ReactNode` | - | Primary call-to-action button |
| `className` | `string` | - | Additional CSS class |

## Common Mistakes

### Using for Loading States

Do not use `EmptyState` while data is fetching. Use a loading spinner or skeleton loader instead. EmptyState implies the fetch completed successfully but returned 0 results.
