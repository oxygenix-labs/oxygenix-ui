# EmptyState

Beautiful empty state component for displaying when no data is available in tables, lists, or dashboards.

## Installation

```bash
npm install @oxygenix-ui/ui
```

## Basic Usage

```tsx
import { EmptyState } from '@oxygenix-ui/ui';

function UserList() {
  if (users.length === 0) {
    return (
      <EmptyState
        title="No users found"
        description="Get started by adding your first user"
      />
    );
  }

  return <UserTable users={users} />;
}
```

## Features

### With Icon

Add an icon or illustration to make the empty state more engaging.

```tsx
import { Users } from 'lucide-react';

<EmptyState
  icon={<Users size={48} />}
  title="No users yet"
  description="Your user list is empty"
/>
```

### With Action Button

Provide a call-to-action to help users get started.

```tsx
<EmptyState
  icon={<Inbox size={48} />}
  title="No messages"
  description="You don't have any messages yet"
  action={
    <Button onClick={() => composeMessage()}>
      Compose Message
    </Button>
  }
/>
```

## API Reference

### EmptyState

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `icon` | `ReactNode` | - | Icon or illustration |
| `title` | `string` | Required | Empty state title |
| `description` | `string` | - | Description text |
| `action` | `ReactNode` | - | Action button or link |
| `className` | `string` | - | Additional CSS class |

## Best Practices

### 1. Provide Clear Guidance

```tsx
// ✅ Good - explains what to do
<EmptyState
  title="No tasks"
  description="Create your first task to get started"
  action={<Button>Create Task</Button>}
/>

// ❌ Bad - no guidance
<EmptyState title="Empty" />
```

### 2. Use Relevant Icons

```tsx
// ✅ Good - icon matches context
<EmptyState
  icon={<Users />}
  title="No team members"
/>

// ❌ Bad - generic icon
<EmptyState
  icon={<Circle />}
  title="No team members"
/>
```

### 3. Offer Actions When Appropriate

```tsx
// ✅ Good - action helps user proceed
<EmptyState
  title="No projects"
  action={<Button>Create Project</Button>}
/>

// ❌ Bad - no way to proceed
<EmptyState title="No projects" />
```

### 4. Keep Text Concise

```tsx
// ✅ Good - concise and clear
<EmptyState
  title="No notifications"
  description="You're all caught up"
/>

// ❌ Bad - too verbose
<EmptyState
  title="You currently have no notifications"
  description="At this moment in time, there are no notifications available for you to view in your notification center"
/>
```

## Use Cases

### Perfect for:
- ✅ Empty tables and lists
- ✅ No search results
- ✅ Empty dashboards
- ✅ Uninitialized states
- ✅ Cleared filters
- ✅ Empty shopping carts

### Not recommended for:
- ❌ Loading states (use Skeleton instead)
- ❌ Error states (use error messages)
- ❌ Form validation (use field errors)

## Accessibility

The EmptyState component is accessible:

- **Semantic HTML**: Uses proper heading hierarchy
- **Screen Readers**: Title and description are readable
- **Keyboard**: Action buttons are keyboard accessible
- **Focus**: Proper focus management
