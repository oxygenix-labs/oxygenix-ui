# Textarea

A multi-line text input component.

## Overview

The Textarea component allows users to enter a significant amount of text. It supports auto-resizing and validation states.

## Accessibility

- **Labeling**: Like inputs, textareas must be labeled. Use `FormField` or standard `<label>` elements.
- **Keyboard Navigation**: Standard keyboard interaction is supported. Tab to focus, type to enter text.

## Props

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `autoResize` | `boolean` | `false` | Automatically adjusts height based on content |
| `error` | `boolean` | `false` | Applies error styling |
| `rows` | `number` | - | Initial number of rows |
| `className` | `string` | - | Additional CSS class |
| ... | `TextareaHTMLAttributes` | - | Standard textarea attributes |

## Common Mistakes

### Controlled vs Uncontrolled

When using `autoResize` in a controlled component (with `value`), ensure you pass the `value` prop to the Textarea so the resize logic triggers on updates.

### Fixed Height conflicts

Avoid setting a fixed CSS `height` when using `autoResize`, as it will conflict with the JavaScript resizing logic. Use `min-height` or `max-height` instead.
