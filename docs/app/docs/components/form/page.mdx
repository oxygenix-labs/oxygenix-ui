# Form System

A set of components to build accessible and consistent forms.

## Overview

The Form System consists of `FormField` and `FormGroup` components. `FormField` wraps an input with a label, helper text, and error message. `FormGroup` groups related fields together.

## Basic Usage

### FormField

Wrap an `Input` (or any control) with `FormField` to add a label.

<LiveCodeBlock>
    <LivePreview>
        <FormField label="Username" htmlFor="username">
            <Input id="username" placeholder="johndoe" />
        </FormField>
    </LivePreview>
    <LiveSource
        code={`import { FormField, Input } from '@oxygenix-ui/ui';

export default function FormFieldDemo() {
  return (
    <FormField label="Username" htmlFor="username">
      <Input id="username" placeholder="johndoe" />
    </FormField>
  );
}`}
        language="tsx"
    />
</LiveCodeBlock>

Use `FormGroup` to organize multiple related fields.

## Accessibility

- **Label Association**: `FormField` handles associating the label with the input via `htmlFor`. **You must provide `htmlFor` on FormField and `id` on the input**.
- **Error Association**: Error messages are automatically linked to inputs via context or aria-describedby (in advanced implementations, simply rendering it below helps, but strict ARIA linkage requires ID referencing).
- **Group Labeling**: `FormGroup` renders a `<fieldset>` with a `<legend>` to accessible group related controls.

## Props

### FormField

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `label` | `string` | - | Label text |
| `htmlFor` | `string` | - | ID of the input to associate with |
| `hint` | `string` | - | Helper text below input |
| `error` | `string` | - | Error message |
| `required` | `boolean` | `false` | Shows required indicator |
| `children` | `ReactNode` | - | The input component |

### FormGroup

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `legend` | `string` | - | Group title (legend) |
| `description` | `string` | - | Helper text for the group |
| `children` | `ReactNode` | - | The form fields |

## Common Mistakes

### Mismatched IDs

The `htmlFor` on `FormField` MUST match the `id` on the `Input`. If they don't match, clicking the label won't focus the input and screen readers won't announce the label.

### Using placeholders as labels

Never rely on placeholders alone. They disappear when the user types and are often not accessible. Always use a visible label.

### Improper Grouping

Use `FormGroup` (fieldset) when you have a collection of related inputs (like a shipping address). Do not use `div`s if the fields are logically connected as a single entity.
