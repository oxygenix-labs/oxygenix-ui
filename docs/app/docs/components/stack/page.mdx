# Stack

A layout utility component for managing vertical and horizontal spacing between elements, similar to Flexbox but with a simplified API.

## Overview

The `Stack` component abstracts common Flexbox patterns to make layout creation faster and more consistent. It handles direction, alignment, justification, and spacing (gap) between children.

## Advanced Usage

You can control the `direction` (horizontal or vertical), `align` (cross-axis), and `justify` (main-axis) properties, as well as customize the `gap`.

    <LivePreview>
        <StackAdvancedDemo />
    </LivePreview>

        code={`import { Stack, Button, Text } from '@oxygenix-ui/ui';

export default function StackAdvancedDemo() {
  return (
    <Stack gap={6}>
      <div>
        <Text style={{ marginBottom: '8px' }}>Horizontal Alignment</Text>
        <Stack direction="horizontal" gap={2} align="center">
          <Button size="sm">Small</Button>
          <Button>Medium</Button>
          <Button size="lg">Large</Button>
        </Stack>
      </div>

      <div>
        <Text style={{ marginBottom: '8px' }}>Justify Content</Text>
        <Stack direction="horizontal" gap={2} justify="between" style={{ background: '#f5f5f5', padding: '12px', borderRadius: '4px' }}>
          <Button variant="outline" size="sm">Left</Button>
          <Button variant="outline" size="sm">Right</Button>
        </Stack>
      </div>
    </Stack>
  );
}`}
        language="tsx"
    />
</LiveCodeBlock>

## Accessibility

-   **Structure**: `Stack` renders a `<div>` by default. It is a layout utility and does not have inherent semantic meaning like `<nav>` or `<main>`. Use semantic HTML elements inside the stack or wrapper styles where appropriate.
-   **Flexbox**: Uses standard CSS Flexbox, so screen readers traverse content in DOM order. Visual order matches DOM order unless explicitly overridden (which `Stack` avoids by default).

## Props

### Stack

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `children` | `ReactNode` | **Required** | Content to arrange |
| `direction` | `'vertical' \| 'horizontal'` | `'vertical'` | Flex direction |
| `align` | `'start' \| 'center' \| 'end' \| 'stretch'` | `'stretch'` | Cross-axis alignment (align-items) |
| `justify` | `'start' \| 'center' \| 'end' \| 'between'` | `'start'` | Main-axis alignment (justify-content) |
| `gap` | `1 \| 2 \| 3 \| 4 \| 5 \| 6 \| 8` | `4` | Spacing between items (mapped to design tokens) |
| `className` | `string` | - | Additional CSS class names |
| `style` | `CSSProperties` | - | Inline styles |

## Common Mistakes

### Using Stack for Everything

While convenient, `Stack` adds a DOM node. For tight lists or complex grids where semantic markup (`<ul>`, `<li>` or CSS Grid) is more appropriate, consider using adjacent sibling selectors in CSS or the `Grid` component.

### Nested Stacks

Nesting many `Stack` components can lead to a deep DOM tree ("div soup"). If you find yourself nesting 4+ levels deep just for layout, consider if a CSS Grid (via the `Grid` component) would be cleaner.
