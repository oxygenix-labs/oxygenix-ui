# Select

A native select component for picking a value from a list of options.

## Overview

The Select component renders a native HTML `<select>` element, ensuring maximum accessibility and mobile compatibility. It accepts options as an array of objects.

## Import

<LiveCodeBlock>
    <LiveSource
        code={`import { Select } from '@oxygenix-ui/ui';`}
        language="tsx"
    />
</LiveCodeBlock>

## Basic Usage

Provide an array of `options` where each option has a `label` and a `value`.

<LiveCodeBlock>
    <LivePreview>
        <Select 
            options={[
                { label: 'Option 1', value: '1' },
                { label: 'Option 2', value: '2' },
                { label: 'Option 3', value: '3' },
            ]} 
        />
    </LivePreview>
    <LiveSource
        code={`import { Select } from '@oxygenix-ui/ui';

  return (
    <Select 
        options={[
            { label: 'Option 1', value: '1' },
            { label: 'Option 2', value: '2' },
            { label: 'Option 3', value: '3' },
        ]} 
    />
  );
}`}
        language="tsx"

## Accessibility

- **Native Controls**: Using the native `<select>` element guarantees high accessibility and familiar behavior on mobile devices (native pickers).
- **Labeling**: Always associate a label via `FormField` or `htmlFor`/`id`.

## Props

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `options` | `{ label: string, value: string, disabled?: boolean }[]` | **Required** | Array of option objects |
| `placeholder` | `string` | - | Text for the default disabled option |
| `error` | `boolean` | `false` | Visual error state |
| `className` | `string` | - | Additional CSS class |
| ... | `SelectHTMLAttributes` | - | Standard select attributes |

## Common Mistakes

### Passing children instead of options

This component expects an `options` prop array, not `<option>` children elements. This enforces a consistent structure.

### Forgetting defaultValue with placeholder

When using a `placeholder`, standard React warnings apply regarding controlled/uncontrolled inputs. If uncontrolled, it's often helpful to set `defaultValue=""` to ensure the placeholder is selected initially.
