# Button

Trigger actions or navigate to new pages.

## Overview

The Button component is used to trigger an action or event, such as submitting a form, opening a dialog, or canceling an action. It supports various styles, sizes, and states.

### With Icons

You can add icons to the left or right of the text using `leftIcon` and `rightIcon` props.

<LiveCodeBlock>
    <LivePreview>

### Loading State

Set the `loading` prop to `true` to show a spinner and disable the button. The width of the button is preserved to prevent layout shift.

<LiveCodeBlock>
    <LivePreview>
        <Flex gap="4">

            <Button loading variant="secondary">Saving...</Button>
        </Flex>
    </LivePreview>
    <LiveSource
        code={`<Button loading>Loading</Button>
<Button loading variant="secondary">Saving...</Button>`}
        language="tsx"
    />
</LiveCodeBlock>

## Accessibility

- Renders a native `<button>` element by default.
- Supports keyboard navigation (Tab to focus, Enter/Space to activate).
- When `loading` is true, the button is disabled and `aria-busy` is set to true.
- Icons are automatically hidden from screen readers using \`aria-hidden\`.

## Props

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `variant` | `'primary' \| 'secondary' \| 'ghost' \| 'danger' \| 'solid' \| 'soft'` | `'primary'` | Visual style of the button |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | Size of the button |
| `loading` | `boolean` | `false` | Shows loading spinner and disables interaction |
| `disabled` | `boolean` | `false` | Disables the button |
| `leftIcon` | `ReactNode` | - | Element to render before the children |
| `rightIcon` | `ReactNode` | - | Element to render after the children |
| `children` | `ReactNode` | - | Content of the button |

## Common Mistakes

### Don't use Buttons for Links

If you need to navigate to another page, use a Link component or an anchor tag styled as a button, unless you are performing an action (like submission) before navigation.

### Don't mix too many variants

Avoid using multiple primary buttons on a single view. Primary buttons should be reserved for the main action of the page.
