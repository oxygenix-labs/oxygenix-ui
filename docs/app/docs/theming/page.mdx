
# Theming

Oxygenix UI features a powerful and flexible theming system built on top of CSS variables and React Context. It supports light and dark modes out of the box, provides a comprehensive set of design tokens, and allows for easy customization.

## Overview

The theming system is designed to be:
- **Zero-runtime overhead**: Most styling is done via CSS variables.
- **Type-safe**: TypeScript tokens are available for CSS-in-JS or inline styles.
- **Dark mode ready**: Semantic colors automatically adapt to the user's preferred color scheme.
- **Enterprise-grade**: Accessible color palettes and consistent spacing/typography scales.

### 3. Setup Theme Provider

Wrap your application with a `ThemeProvider` to manage light/dark mode state. While `next-themes` is a popular choice, here is a simple implementation you can use:

<LiveCodeBlock>
  <LiveSource
    language="tsx"
    filename="components/ThemeProvider.tsx"
    code={`'use client';

import { createContext, useContext, useEffect, useState } from 'react';

type Theme = 'light' | 'dark';

const ThemeContext = createContext({
  theme: 'light' as Theme,
  setTheme: (theme: Theme) => {},
  toggleTheme: () => {},
});

export function ThemeProvider({ children }: { children: React.ReactNode }) {
  const [theme, setThemeState] = useState<Theme>('light');

  useEffect(() => {
    // Check local storage or system preference
    const stored = localStorage.getItem('theme') as Theme | null;
    const system = window.matchMedia('(prefers-color-scheme: dark)').matches ? 'dark' : 'light';
    const initial = stored || system;
    
    setThemeState(initial);
    document.documentElement.setAttribute('data-theme', initial);
  }, []);

  const setTheme = (newTheme: Theme) => {
    setThemeState(newTheme);
    localStorage.setItem('theme', newTheme);
    document.documentElement.setAttribute('data-theme', newTheme);
  };

  const toggleTheme = () => setTheme(theme === 'light' ? 'dark' : 'light');

  return (
    <ThemeContext.Provider value={{ theme, setTheme, toggleTheme }}>
      {children}
    </ThemeContext.Provider>
  );
}

export const useTheme = () => useContext(ThemeContext);`}
  />
</LiveCodeBlock>

Then use it in your layout:

<LiveCodeBlock>
  <LiveSource
    language="tsx"
    filename="app/layout.tsx"
    code={`import { ThemeProvider } from '@/components/ThemeProvider';

export default function RootLayout({ children }) {
  return (
    <html lang="en">
      <body>
        <ThemeProvider>
          {children}
        </ThemeProvider>
      </body>
    </html>
  );
}
`}
  />
</LiveCodeBlock>

## Design Tokens

Oxygenix UI provides a comprehensive set of design tokens tailored for enterprise applications.

### Colors

Colors are organized into **Primitives** (raw values) and **Semantics** (functional usage).

#### Semantic Colors (Recommended)

Use these variables to ensuring automatic dark mode support.

| Token | CSS Variable | Description |
| :--- | :--- | :--- |
| **Methods** | | |
| Primary | `--oxy-primary-600` | Main brand color |
| Background | `--oxy-color-bg-primary` | Main page background |
| Surface | `--oxy-color-bg-secondary` | Cards, sidebars, headers |
| Text | `--oxy-color-text-primary` | Main body text |
| Muted Text | `--oxy-color-text-secondary` | Secondary/helper text |
| Border | `--oxy-color-border-default` | Default border color |

#### Color Palette

The primitive palette includes `gray`, `primary` (blue), `success` (green), `warning` (amber), and `error` (red).

## Dark Mode

Dark mode is handled automatically via semantic tokens. The `data-theme="dark"` attribute on the `<html>` or `<body>` tag triggers the dark theme values.

<LiveCodeBlock>
  <LiveSource
    language="css"
    code={`/* How it works internally */
:root {
  --oxy-color-bg-primary: #ffffff;
  --oxy-color-text-primary: #171717;
}

[data-theme="dark"] {
  --oxy-color-bg-primary: #171717;
  --oxy-color-text-primary: #fafafa;
}`}
  />
</LiveCodeBlock>

## Customization

You can override any token by defining it in your own global CSS file. Ensure your CSS is imported **after** the Oxygenix theme.

<LiveCodeBlock>
  <LiveSource
    language="css"
    filename="styles/globals.css"
    code={`:root {
  /* Change primary color to Purple */
  --oxy-primary-500: #8b5cf6;
  --oxy-primary-600: #7c3aed;
  
  /* Increase base radius */
  --oxy-radius-base: 8px;
  
  /* Custom font */
  --oxy-font-family-sans: 'Geist', sans-serif;
}`}
  />
</LiveCodeBlock>

## Runtime Switching

To switch themes at runtime, use the `useTheme` hook exposed by your `ThemeProvider`.

<LiveCodeBlock>
  <LiveSource
    language="tsx"
    code={`import { useTheme } from '@/components/ThemeProvider';
import { Button } from '@oxygenix-ui/ui';
import { Sun, Moon } from 'lucide-react';

export function ThemeToggle() {
  const { theme, toggleTheme } = useTheme();

  return (
    <Button variant="ghost" size="icon" onClick={toggleTheme}>
      {theme === 'light' ? <Moon size={18} /> : <Sun size={18} />}
    </Button>
  );
}
`}
  />
</LiveCodeBlock>
