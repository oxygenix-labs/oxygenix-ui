# Pagination

A navigation component that allows users to browse through large sets of data using numbered pages.

## Overview

The `Pagination` component handles the logic for rendering page numbers, ellipsis for large ranges, and previous/next controls. It is a controlled component, meaning you must manage the current page state.

## Basic Usage

You must provide `currentPage`, `totalPages`, and an `onPageChange` handler.

import PaginationBasicDemo from './PaginationBasicDemo';
import PaginationAdvancedDemo from './PaginationAdvancedDemo';

<LiveCodeBlock>
    <LivePreview>
        <PaginationBasicDemo />

        code={`import { Pagination, Text } from '@oxygenix-ui/ui';
import { useState } from 'react';

export default function PaginationBasicDemo() {

## Advanced Usage

You can display information about the current range of items being viewed using `showInfo`, `totalItems`, and `pageSize`.

<LiveCodeBlock>
    <LivePreview>
        <PaginationAdvancedDemo />
    </LivePreview>

import { useState } from 'react';

export default function PaginationAdvancedDemo() {
  const [currentPage, setCurrentPage] = useState(1);
  const totalItems = 125;
  const pageSize = 10;
  const totalPages = Math.ceil(totalItems / pageSize);

  return (
    <Pagination
        currentPage={currentPage}
        totalPages={totalPages}
        onPageChange={setCurrentPage}
        showInfo
        totalItems={totalItems}
        pageSize={pageSize}
    />
  );
}`}

    />
</LiveCodeBlock>

## Accessibility

-   **Navigation**: The component uses button elements for all interactive controls.
-   **Current Page**: The current page button receives `aria-current="page"`.
-   **Labels**: Previous and Next buttons have `aria-label` attributes ("Previous page", "Next page").
-   **Ellipsis**: Ellipsis indicators are visual only and do not receive focus.

## Props

### Pagination

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `currentPage` | `number` | **Required** | The current active page (1-based index) |
| `totalPages` | `number` | **Required** | Total number of pages |
| `onPageChange` | `(page: number) => void` | **Required** | Handler called when a page is selected |
| `siblingCount` | `number` | `1` | Number of always-visible pages before and after the current page |
| `showInfo` | `boolean` | `false` | Whether to show the "Showing X-Y of Z" text |
| `totalItems` | `number` | - | Total number of items (required if `showInfo` is true) |
| `pageSize` | `number` | - | Items per page (required if `showInfo` is true) |
| `className` | `string` | - | Additional CSS class names |

## Common Mistakes

### Zero-based Indexing

The `Pagination` component uses **1-based indexing** for `currentPage`. Ensure your state initialization starts at 1, not 0.

### Missing Total Pages

You must calculate `totalPages` yourself if you only have `totalItems` and `pageSize`. A common formula is `Math.ceil(totalItems / pageSize)`.
