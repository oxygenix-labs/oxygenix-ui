# Sidebar

A collapsible sidebar navigation component that supports custom headers, footers, and responsive behavior.

## Overview

The `Sidebar` component provides a standard vertical navigation layout. It handles collapsed states, toggle interactions, and rendering of navigation items with icons. It is designed to work seamlessly within the `AppShell` or as a standalone component.

## Accessibility

-   **Semantic Elements**: Uses `<nav>` and `<ul>`/`<li>` for navigation structure.
-   **ARIA Attributes**:
    -   `aria-expanded` on the toggle button.
    -   `aria-current="page"` on the active navigation link.
    -   `aria-disabled` on disabled items.
-   **Keyboard Navigation**: Supports tab navigation through links and interactive elements.

## Props

### Sidebar

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `navItems` | `SidebarNavItem[]` | - | Array of navigation items to render |
| `header` | `ReactNode` | - | Content rendered at the top of the sidebar |
| `footer` | `ReactNode` | - | Content rendered at the bottom of the sidebar |
| `children` | `ReactNode` | - | Custom content (overrides `navItems` rendering) |
| `collapsed` | `boolean` | - | Controlled collapsed state |
| `defaultCollapsed` | `boolean` | `false` | Initial collapsed state |
| `onCollapsedChange` | `(collapsed: boolean) => void` | - | Callback when collapsed state changes |
| `showToggle` | `boolean` | `true` | Whether to show the collapse toggle button |
| `className` | `string` | - | Additional CSS class names |

### SidebarNavItem

| Property | Type | Description |
| :--- | :--- | :--- |
| `id` | `string` | Unique identifier for the item |
| `label` | `string` | Text label for the item |
| `icon` | `ReactNode` | Icon element to display |
| `href` | `string` | URL for link items (renders `<a>`) |
| `onClick` | `() => void` | Click handler (renders `<button>` if no href) |
| `active` | `boolean` | Whether the item is currently active |
| `disabled` | `boolean` | Whether the item is disabled |

## Common Mistakes

### Incorrect Import Source

The `Sidebar` component documented here is part of the `@oxygenix-ui/layout` package. Be careful not to import `Sidebar` from `@oxygenix-ui/ui` if you're looking for this specific implementation, as they may have different APIs.

<LiveCodeBlock>
    <LiveSource
        code={`// ✅ Correct
import { Sidebar } from '@oxygenix-ui/layout';

// ❌ Incorrect (for this usage)
import { Sidebar } from '@oxygenix-ui/ui';`}
        language="tsx"
    />
</LiveCodeBlock>

### Missing Keys

When providing `navItems`, ensure each item has a unique `id`. This is used as the `key` for the list items.

### Content Overflow

When using `collapsed` state with custom `header` or `footer`, ensure your content handles the narrow width gracefully (e.g., hiding text when collapsed), as shown in the Advanced Usage example.
