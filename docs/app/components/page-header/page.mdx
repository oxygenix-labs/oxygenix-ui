# PageHeader

A layout component that renders a standard page header with a title, subtitle, breadcrumbs, and action buttons.

## Overview

The `PageHeader` component provides a consistent header structure for application pages. It automatically handles the layout of breadcrumbs above the title, and positions action buttons to the right side of the header.

## Accessibility

-   **Semantic Navigation**: Breadcrumbs are wrapped in a `<nav>` element with `aria-label="Breadcrumb"`.
-   **Current Page**: The last breadcrumb item (if not a link) automatically receives `aria-current="page"`.
-   **Heading**: The title uses an `<h1>` element by default for proper page hierarchy.

## Props

### PageHeader

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `title` | `string` | **Required** | The main heading of the page |
| `subtitle` | `string` | - | Secondary text below the title |
| `breadcrumbs` | `BreadcrumbItem[]` | `[]` | Array of breadcrumb items |
| `actions` | `ReactNode` | - | Content to render on the right side (usually buttons) |
| `className` | `string` | - | Additional CSS class names |

### BreadcrumbItem

| Property | Type | Description |
| :--- | :--- | :--- |
| `label` | `string` | Text to display |
| `href` | `string` | URL link (if present, renders an anchor tag) |
| `onClick` | `() => void` | Click handler |

## Common Mistakes

### Complex Actions

The `actions` prop is designed for a few primary buttons. Avoid putting complex forms or large content blocks in this area, as it may break the responsive layout on smaller screens.

### Breadcrumb Structure

Ensure the `breadcrumbs` array is ordered from the root (home) to the current page. The component automatically handles separators and the styling of the active (last) item.
