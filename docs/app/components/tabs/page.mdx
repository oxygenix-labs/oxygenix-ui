# Tabs

A set of layered sections of content—known as tab panels—that are displayed one at a time.

## Overview

The `Tabs` component follows the WAI-ARIA Tabs pattern. It supports keyboard navigation (left/right arrows) and lazy loading of content.

## Basic Usage

The `Tabs` component is composed of `TabsList`, `TabsTrigger`, and `TabsContent`. Use `defaultValue` to set the initially active tab.

import TabsBasicDemo from './TabsBasicDemo';
import TabsAdvancedDemo from './TabsAdvancedDemo';

## Advanced Usage

You can control the active tab state programmatically using `value` and `onValueChange`. Tabs can also be disabled.

<LiveCodeBlock>
    <LivePreview>
        <TabsAdvancedDemo />
    </LivePreview>
    <LiveSource
        code={`import { Tabs, TabsList, TabsTrigger, TabsContent, Button } from '@oxygenix-ui/ui';
import { useState } from 'react';

export default function TabsAdvancedDemo() {
  const [activeTab, setActiveTab] = useState('tab1');

  return (
    <div>
      <div style={{ marginBottom: '16px' }}>
          <Button size="sm" onClick={() => setActiveTab('tab3')}>Jump to Tab 3</Button>
      </div>

      <Tabs value={activeTab} onValueChange={setActiveTab}>
        <TabsList>
          <TabsTrigger value="tab1">First Tab</TabsTrigger>
          <TabsTrigger value="tab2">Second Tab</TabsTrigger>
          <TabsTrigger value="tab3">Third Tab</TabsTrigger>
          <TabsTrigger value="tab4" disabled>Disabled Tab</TabsTrigger>
        </TabsList>
        <div style={{ padding: '16px', border: '1px solid #e5e7eb' }}>
            <TabsContent value="tab1">Content for the first tab.</TabsContent>
            <TabsContent value="tab2">Content for the second tab.</TabsContent>
            <TabsContent value="tab3">Content for the third tab.</TabsContent>
        </div>
      </Tabs>
    </div>
  );
}`}
        language="tsx"
    />
</LiveCodeBlock>

## Accessibility

-   **Roles**:
    -   `TabsList`: `role="tablist"`
    -   `TabsTrigger`: `role="tab"`
    -   `TabsContent`: `role="tabpanel"`
-   **Keyboard Navigation**:
    -   `ArrowRight` / `ArrowLeft`: Moves focus between tabs.
    -   `Home` / `End`: Moves focus to the first or last tab.
    -   `Enter` / `Space`: Activates the selected tab.
-   **ARIA Attributes**:
    -   `aria-selected`: Indicates the active tab.
    -   `aria-controls`: Connects the tab to its panel.
    -   `aria-labelledby`: Connects the panel to its tab.

## Props

### Tabs

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `defaultValue` | `string` | - | The value of the tab to select by default (uncontrolled) |
| `value` | `string` | - | The controlled value of the tab to select |
| `onValueChange` | `(value: string) => void` | - | Callback when the value changes |
| `children` | `ReactNode` | - | Contains `TabsList` and `TabsContent` |

### TabsList

| Prop | Type | Description |
| :--- | :--- | :--- |
| `children` | `ReactNode` | Contains `TabsTrigger` items |

### TabsTrigger

| Prop | Type | Description |
| :--- | :--- | :--- |
| `value` | `string` | Unique value identifying the tab |
| `disabled` | `boolean` | Whether the tab is disabled |
| `children` | `ReactNode` | Tab label content |

### TabsContent

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `value` | `string` | **Required** | Must match the `value` of the associated `TabsTrigger` |
| `lazy` | `boolean` | `true` | If true, content is not mounted until the tab is active |
| `children` | `ReactNode` | - | The content to display |
