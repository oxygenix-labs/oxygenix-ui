# FormGroup

A container component for grouping related form controls.

## Overview

The FormGroup component helps organize complex forms by grouping related fields together. It renders as a semantic `<fieldset>` with a `<legend>`.

## Accessibility

- **Semantic HTML**: Renders a `<fieldset>`, which is the correct element for grouping form controls.
- **Legend**: Renders a `<legend>`, which provides an accessible name for the group. Screen readers will often announce the legend when the user navigates into the group.

## Props

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `legend` | `string` | - | The title of the group |
| `description` | `string` | - | Helper text describing the group |
| `children` | `ReactNode` | - | The form controls to group |
| `className` | `string` | - | Additional CSS class |

## Common Mistakes

### Using for layout only

Do not use `FormGroup` just to put a border or title around generic content. Use it specifically for grouping *form controls* that are logically related.

### Nested FormGroups

Avoid nesting generic `FormGroup`s too deeply, as it can be confusing for screen reader navigation. Use headings (`h3`, `h4`) for subgroupings if necessary inside a larger form.
