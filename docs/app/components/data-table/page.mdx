# Data Table

An advanced table component with support for sorting, pagination, and row selection.

## Overview

The Data Table component is designed to display large datasets in a structured format. It provides built-in features for managing data presentation without the need for complex external logic for basic use cases.

## Accessibility

- **Semantic Table**: Renders standard HTML `table`, `thead`, `tbody`, `tr`, `th`, and `td` elements.
- **Keyboard Navigation**: Native focus management for embedded interactive elements.
- **ARIA**: Includes ARIA labels for pagination and sorting indicators.

## Props

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `columns` | `TableColumn[]` | **Required** | Column definitions |
| `data` | `T[]` | **Required** | Array of data objects |
| `pagination` | `boolean` | `false` | Enable pagination |
| `pageSize` | `number` | `10` | Rows per page |
| `selectable` | `boolean` | `false` | Enable row selection checkboxes |
| `onSelectionChange` | `(keys: Set) => void` | - | Handler for selection changes |
| `className` | `string` | - | Additional CSS class |

### TableColumn Definition

| Property | Type | Description |
| :--- | :--- | :--- |
| `key` | `string` | Property key in data object |
| `label` | `string` | Header text |
| `sortable` | `boolean` | Enable sorting for this column |
| `render` | `(val, row, index) => ReactNode` | Custom cell content |
| `width` | `string \| number` | Column width |
| `align` | `'left' \| 'center' \| 'right'` | Text alignment |

## Common Mistakes

### Missing Keys

The `key` property in `columns` must strictly match the property names in your `data` objects. If they don't match, the cell will appear empty.

### Sorting non-primitive values

Default sorting works best on strings and numbers. For complex objects, you may need to implement custom sorting logic (via `onSortChange`) or flatten your data structure.
