# AppShell

The fundamental layout component for building applications with a header, sidebar, and main content area.

## Overview

AppShell provides a responsive shell for your application. It handles the positioning of the sidebar, header, and main content, ensuring a consistent layout structure across your app.

## Props

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `children` | `ReactNode` | **Required** | The main content of the application |
| `header` | `ReactNode` | - | Content to display at the top |
| `sidebar` | `ReactNode` | - | Content to display on the side |
| `className` | `string` | - | Additional CSS class for the root element |

## Common Mistakes

### Missing Height Constraint

`AppShell` is designed to fill the available space. Ensure its parent container has a defined height (e.g., `h-screen`) so the layout works as expected.

### Sidebar Width

The `AppShell` does not enforce a width on the sidebar content. You must ensure the content passed to the `sidebar` prop has a defined width, or it might collapse.
