# Alert

Displays a callout for user attention.

## Overview

Alerts are used to communicate a state that affects a system, feature, or page. They come in four variants: `info`, `success`, `warning`, and `error`.

## Basic Usage

The `Alert` component accepts a `title` and `description`. Use the `variant` prop to change the style.

import AlertBasicDemo from './AlertBasicDemo';
import AlertAdvancedDemo from './AlertAdvancedDemo';

<LiveCodeBlock>
    <LivePreview>
        <AlertBasicDemo />
    </LivePreview>

        code={`import { Alert } from '@oxygenix-ui/ui';

## Advanced Usage

You can make alerts `closable`, utilize `onClose` callbacks, and provide a custom `icon`.

<LiveCodeBlock>
    <LivePreview>
        <AlertAdvancedDemo />
    </LivePreview>
    <LiveSource
        code={`import { Alert } from '@oxygenix-ui/ui';
import { Rocket } from 'lucide-react';

export default function AlertAdvancedDemo() {
  return (
    <div style={{ display: 'flex', flexDirection: 'column', gap: '16px' }}>
      <Alert 
        icon={<Rocket size={18} />}
        title="New Features Available" 
        description="Check out the new version of Oxygenix UI!" 
      />

      <Alert 
        variant="info"
        title="Dismissible Alert" 
        description="You can close this alert by clicking the X button." 
        closable
        onClose={() => console.log('Alert closed')}
      />
    </div>
  );
}`}
        language="tsx"
    />
</LiveCodeBlock>

## Accessibility

-   **Role**: `role="alert"` is applied automatically. This alerts screen readers immediately when the component renders.
-   **Dismissal**: The close button has an `aria-label="Close alert"`.

## Props

### Alert

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `title` | `string` | - | Valid title for the alert |
| `description` | `ReactNode` | - | Detailed description text |
| `variant` | `'info' \| 'success' \| 'warning' \| 'error'` | `'info'` | Visual style variant |
| `icon` | `ReactNode` | - | Custom icon to override default |
| `closable` | `boolean` | `false` | Shows a close button |
| `onClose` | `() => void` | - | Handler called when closed |
| `className` | `string` | - | Additional CSS class names |
