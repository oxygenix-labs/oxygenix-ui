# Toast

A floating notification that automatically dismisses after a delay.

## Overview

Toasts are used for non-blocking feedback about an operation. They "pop up" over content and usually disappear on their own.

## Basic Usage

Wrap your application (or just the demo area) in `ToastContainer`. Render `Toast` components inside it when you want them to appear.

import ToastBasicDemo from './ToastBasicDemo';
import ToastAdvancedDemo from './ToastAdvancedDemo';

<LiveCodeBlock>
    <LivePreview>
        <ToastBasicDemo />
    </LivePreview>
    <LiveSource
        code={`import { Toast, ToastContainer, Button } from '@oxygenix-ui/ui';
import { useState } from 'react';

export default function ToastBasicDemo() {
  const [showToast, setShowToast] = useState(false);

  return (
    <>
      <Button onClick={() => setShowToast(true)}>
        Show Toast
      </Button>

      <ToastContainer>
        {showToast && (
          <Toast 
            title="Notification" 
            description="This is a floating notification."
            onClose={() => setShowToast(false)}
          />
        )}
      </ToastContainer>
    </>
  );
}`}
        language="tsx"
    />
</LiveCodeBlock>

## Advanced Usage

Control the `position` of the container and use `variant` to indicate different statuses. You can also manage a list of toasts.

<LiveCodeBlock>
    <LivePreview>
        <ToastAdvancedDemo />
    </LivePreview>
    <LiveSource
        code={`import { Toast, ToastContainer, Button } from '@oxygenix-ui/ui';
import { useState } from 'react';

export default function ToastAdvancedDemo() {
  const [toasts, setToasts] = useState([]);

  const addToast = (variant) => {
    const id = Date.now();
    setToasts((prev) => [...prev, { id, title: \`New \${variant} message\`, variant }]);
  };

  const removeToast = (id) => {
    setToasts((prev) => prev.filter((t) => t.id !== id));
  };

  return (
    <>
      <div style={{ display: 'flex', gap: '8px' }}>
        <Button onClick={() => addToast('info')}>Info</Button>
        <Button onClick={() => addToast('success')}>Success</Button>
      </div>

      <ToastContainer position="bottom-right">
        {toasts.map((toast) => (
          <Toast
            key={toast.id}
            variant={toast.variant}
            title={toast.title}
            duration={3000}
            onClose={() => removeToast(toast.id)}
          />
        ))}
      </ToastContainer>
    </>
  );
}`}
        language="tsx"
    />
</LiveCodeBlock>

## Accessibility

-   **Role**: `role="alert"` is used for immediate feedback, though `role="status"` might be more appropriate for non-critical updates. The current implementation uses `role="alert"`.
-   **Live Region**: `aria-live="polite"` ensures screen readers announce the toast without interrupting the user immediately.

## Props

### Toast

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `title` | `string` | **Required** | Title of the toast |
| `description` | `string` | - | Secondary text |
| `variant` | `'info' \| 'success' \| 'warning' \| 'error'` | `'info'` | Visual variant |
| `duration` | `number` | `5000` | Time in ms before auto-dismiss (0 to disable) |
| `onClose` | `() => void` | - | Callback when closed or auto-dismissed |
| `icon` | `ReactNode` | - | Custom icon |

### ToastContainer

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `position` | `ToastPosition` | `'top-right'` | Where toasts appear on screen (e.g., `'top-right'`, `'bottom-center'`) |
| `children` | `ReactNode` | - | `Toast` components to render |
