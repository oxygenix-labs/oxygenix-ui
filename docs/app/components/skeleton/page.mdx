# Skeleton

Display a placeholder preview of your content before the data gets loaded to reduce load-time frustration.

## Overview

The Skeleton component provides a layout-aware loading state. It mimics the structure of the content that will be loaded, creating a smoother user experience than a blank screen or a spinner.

## Advanced Usage

### Variants

The `Skeleton` component comes with different variants to match standard UI elements: `text`, `title`, `avatar`, `rect`, and `circle`.

<LiveCodeBlock>
    <LivePreview>
        <Flex direction="column" gap="4">
            <Flex align="center" gap="4">
                <Skeleton variant="avatar" width={40} height={40} />
                <div className="w-[200px]">
                    <Skeleton variant="title" width="60%" />
                    <Skeleton variant="text" />
                </div>
            </Flex>
            <Skeleton variant="rect" height={100} />
        </Flex>
    </LivePreview>
    <LiveSource
        code={`import { Skeleton, Flex } from '@oxygenix-ui/ui';

export default function VariantsDemo() {
  return (
    <Flex direction="column" gap="4">
      {/* Profile Card Mockup */}
      <Flex align="center" gap="4">
        <Skeleton variant="avatar" width={40} height={40} />
        <div className="w-[200px]">
          <Skeleton variant="title" width="60%" />
          <Skeleton variant="text" />
        </div>
      </Flex>

      {/* Image Mockup */}
      <Skeleton variant="rect" height={100} />
    </Flex>
  );
}`}
        language="tsx"
    />
</LiveCodeBlock>

## Accessibility

- **ARIA**: Automatically includes `aria-hidden="true"` since skeletons are decorative placeholders.
- **Focus**: Elements are not focusable.

## Props

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `variant` | `'text' \| 'title' \| 'avatar' \| 'rect' \| 'circle'` | `'text'` | Visual style of the skeleton |
| `width` | `string \| number` | - | Width of the skeleton |
| `height` | `string \| number` | - | Height of the skeleton |
| `borderRadius` | `string \| number` | - | Custom border radius |
| `count` | `number` | `1` | Number of lines (useful for text variants) |
| `style` | `CSSProperties` | - | Inline styles |
| `className` | `string` | - | Additional CSS class |

## Common Mistakes

### Mismatched Dimensions

Ensure the `width` and `height` of your `Skeleton` roughly match the content it is replacing. This prevents "layout shift" when the real content loads.

### Overusing Animations

If you have many skeletons on a page, the pulsing animation can be distracting. Consider a static background color for very dense grids.
