# Progress

Displays an indicator showing the completion progress of a task, typically displayed as a progress bar.

## Overview

The `Progress` component is used to visually represent the status of an ongoing operation, such as a download, file upload, or form processing.

## Basic Usage

The `Progress` component accepts a `value` prop between 0 and 100. You can also add a `label` and `showValue` to display the percentage.

import ProgressBasicDemo from './ProgressBasicDemo';
import ProgressAdvancedDemo from './ProgressAdvancedDemo';

<LiveCodeBlock>
    <LivePreview>
        <ProgressBasicDemo />
    </LivePreview>
    <LiveSource
        code={`import { Progress } from '@oxygenix-ui/ui';
import { useState, useEffect } from 'react';

export default function ProgressBasicDemo() {
  const [value, setValue] = useState(0);

  useEffect(() => {
    const timer = setInterval(() => {
      setValue((v) => (v >= 100 ? 0 : v + 10));
    }, 1000);
    return () => clearInterval(timer);
  }, []);

  return (
    <div style={{ display: 'flex', flexDirection: 'column', gap: '24px' }}>
        <Progress value={50} label="Static Progress (50%)" showValue />
        <Progress value={value} label="Animated Progress" showValue />
    </div>
  );
}`}
        language="tsx"
    />
</LiveCodeBlock>

## Advanced Usage

Customize the appearance with `variant` (primary, success, warning, error), `size` (sm, md, lg), or use `indeterminate` state when the completion time is unknown.

<LiveCodeBlock>
    <LivePreview>
        <ProgressAdvancedDemo />
    </LivePreview>
    <LiveSource
        code={`import { Progress } from '@oxygenix-ui/ui';

export default function ProgressAdvancedDemo() {
  return (
    <div style={{ display: 'flex', flexDirection: 'column', gap: '24px' }}>
      {/* Variants */}
      <Progress value={75} variant="success" label="Success" />
      <Progress value={50} variant="warning" label="Warning" />
      <Progress value={25} variant="error" label="Error" />

      {/* Indeterminate */}
      <Progress indeterminate label="Loading..." />

      {/* Sizes */}
      <Progress value={40} size="sm" label="Small" />
      <Progress value={80} size="lg" label="Large" />
    </div>
  );
}`}
        language="tsx"
    />
</LiveCodeBlock>

## Accessibility

-   **Role**: `role="progressbar"`.
-   **ARIA Attributes**: `aria-valuenow`, `aria-valuemin`, and `aria-valuemax` are handled automatically.
-   **Labeling**: If `label` is provided, `aria-label` is set to the label text.

## Props

### Progress

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `value` | `number` | `0` | Progress value (0-100) |
| `variant` | `'primary' \| 'success' \| 'warning' \| 'error'` | `'primary'` | Visual style variant |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | Height of the progress bar |
| `label` | `string` | - | Text label displayed above the bar |
| `showValue` | `boolean` | `false` | Shows the percentage value next to the label |
| `indeterminate` | `boolean` | `false` | Shows an animated indeterminate state |
| `className` | `string` | - | Additional CSS class names |
